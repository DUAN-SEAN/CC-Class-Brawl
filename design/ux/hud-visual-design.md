# HUD 视觉设计规格 (HUD Visual Design Specification)

> **Status**: Complete — Pending Review
> **Author**: art-director + user
> **Last Updated**: 2026-05-24
> **Base Resolution**: 1920x1080
> **Rendering**: Screen Space - Overlay, UI Toolkit (UXML/USS) per ADR-0014

---

## Decision Log

本文档基于 `design/ux/hud.md`（UX 规格）和 `design/gdd/battle-hud.md`（技术 GDD）构建视觉层。以下 6 项关键设计决策由用户确认：

| # | 决策点 | 选项 | 最终决定 | 理由 |
|---|--------|------|---------|------|
| A | HUD 布局 | Art Bible §7.4 顶部布局 vs hud.md 底部角落实战布局 | **底部角落布局**（P1 左下、P2 右下） | hud.md 经过 UX 验证，布局更贴合实际战斗可读性。Art Bible §7.4 为通用 UI 方向，战斗 HUD 以 hud.md 为准 |
| B | 动画缓动 | Art Bible §7.3 禁用 EaseOutBack vs 战斗反馈需要弹性感 | **EaseOutBack 仅用于伤害%弹跳和 KO 弹出**；其余全部使用 Cubic ease-out | 战斗核心反馈（伤害数字、KO）需要「冲击感」，但限制在 2 个动画点避免全局弹性化。其余保持硬边利落感 |
| C | 危险色系 | 使用 Art Bible 色板 vs HUD 专用色 | **HUD 专用信息编码色**：黄色 #FFD700、橙色 #FF8C00、红色闪烁 #FF2020 | 这些颜色不属于 Art Bible §4.1 基础色板，但作为 HUD 语义编码（危险等级）不可或缺。仅限 HUD 使用，不进入战斗特效 |
| D | 伤害%字号 | Art Bible 建议 48-64px 范围 | **固定 56px Medium** | 单一确定值便于精确布局和对比度计算。56px 在 2 米外可读（参考 hud.md 可读性要求），且与信息区 ~540px 总宽协调 |
| E | 信息区宽度 | hud.md 建议 ~350px vs 扩展宽度 | **~540px/侧**（保留 48px 技能槽） | 伤害% + 专注值条 + 4 个技能槽在 48px 尺寸下需要 ~520px 内容宽度，加内边距需 ~540px |
| F | 稀有度边框色 | battle-hud GDD 旧色值 vs Art Bible §7.2 色值 | **统一到 Art Bible**：Common #FFFFFF 1px、Rare #9B59B6 2px + glow、Epic #F0C040 3px + glow | 单一数据源，避免色板分裂。Art Bible 是视觉规范的最高权威 |

## 1. Typography System

### 1.1 字体族分配

| 用途 | 字体 | 字重 | 回退字体 | 说明 |
|------|------|------|---------|------|
| 伤害百分比 | Exo 2 | Medium (500) | Noto Sans SC | 等宽数字（tabular-nums），几何无衬线 |
| 比分 / 回合 | Exo 2 | SemiBold (600) | Noto Sans SC | 等宽数字，中等信息层级 |
| KO 文字 | Exo 2 | Bold (700) | Noto Sans SC | 全屏最大文字，系统级冲击 |
| 技能按键提示 | Exo 2 | Medium (500) | Noto Sans SC | 强制大写，最小可读尺寸 |
| 专注值 "MAX" 标签 | Exo 2 | Medium (500) | Noto Sans SC | 状态标签，中等信息层级 |
| 赛点标记 "●" | Exo 2 | Bold (700) | Noto Sans SC | 单字符脉动标记 |

**字体渲染设置**：
- 所有数字启用 `font-variant-numeric: tabular-nums`（防止宽度抖动）
- 中英文混排：英文/数字使用 Exo 2，中文自动回退 Noto Sans SC
- 行高取两种字体的较大值

### 1.2 排版尺度表

| 元素 | 字号 | 字重 | 字间距 | 行高 | 色彩 | 备注 |
|------|------|------|--------|------|------|------|
| 伤害百分比 | 56px | Medium (500) | 2.8px (5%) | 78px (140%) | 按 §2 危险等级 | 等宽数字；">999" 显示 "999+" |
| 比分数字 | 28px | SemiBold (600) | 1.1px (4%) | 39px (140%) | #FFFFFF | 格式 "1 - 0" |
| 回合文字 | 18px | Regular (400) | 0.7px (4%) | 25px (140%) | #E8E8F0 | 格式 "R2/3" |
| KO 文字 | 84px | Bold (700) | 4.2px (5%) | 118px (140%) | #FFFFFF + 胜者职业色描边 | 系统级大字 |
| 技能按键提示 | 12px | Medium (500) | 0.5px (4%) | 17px (140%) | #E8E8F0 | 强制大写；P1: "1/2/3/4"，P2: 可配置 |
| 专注值 "MAX" | 10px | Medium (500) | 0.4px (4%) | 14px (140%) | #666666 | 仅在满值时显示 |
| 赛点标记 "●" | 28px | Bold (700) | — | — | #FFD700（脉动） | 领先方分数旁 |

**排版硬规则**（来源：Art Bible §7.1）：
- 字间距 = 字号的 3-5%（表中已按 4-5% 计算）
- 行高 = 字号的 140-160%（统一使用 140%）
- 最小字号 10px（"MAX" 标签刚好在下限）
- 所有数字使用 tabular-nums 特性

## 2. HUD Color Palette

### 2.1 职业身份色

| 职业 | 色值 | 用途 | 亮度（相对 #1A1A2E） |
|------|------|------|---------------------|

### 2.2 伤害百分比危险等级色（HUD 专用）

| 等级 | 色值 | 触发条件 | 附加效果 | 对比度（vs #1A1A2E 90%） |
|------|------|---------|---------|-------------------------|
| 安全（白） | #FFFFFF | 0%–49% | 无 | 15.4:1 |

| 危险（橙） | #FF8C00 | 100%–149% | 无 | 8.1:1 |
| 致命（红闪） | #FF2020 | 150%+ | 0.5Hz 闪烁（亮 0.5s / 暗 0.5s） | 4.2:1 |

**颜色过渡**：阈值跨越时 0.2s ease-in-out 平滑过渡，不跳变。

### 2.4 稀有度边框色（来源：Art Bible §7.2）

| 稀有度 | 边框色 | 线宽 | 外发光 | 额外效果 |
|--------|--------|------|--------|---------|
| 普通 (Common) | #FFFFFF | 1px 实线 | 无 | 无 |
| 稀有 (Rare) | #9B59B6 | 2px 实线 | blur 3px, opacity 30% | 静止状态微弱脉动（亮度周期 5% 波动） |
| 史诗 (Epic) | #F0C040 | 3px 实线 | blur 5px, opacity 50% | 持续旋转光晕（2px 金色细线沿边框缓慢旋转，约 4s/圈） |

**色盲安全备用通道**（Art Bible §7.5.3）：稀有度同时通过线宽差异（1/2/3px）和图案差异（纯线/虚线/宽线+旋转光晕）传达，不完全依赖颜色。

### 2.5 专注值条色彩

## 3. Per-Element Visual Spec

### 3.1 伤害百分比 (Damage Percent)

| 属性 | 规格 |
|------|------|
| **字体** | Exo 2 Medium (500) |
| **字号** | 56px，固定 |
| **数字特性** | tabular-nums（等宽数字，防止宽度抖动） |
| **字间距** | 2.8px（5%） |
| **行高** | 78px (140%) |
| **格式** | `Floor(DamagePercent)` + "%" 后缀；>999 显示 "999+"；负数钳制为 0% |
| **颜色编码** | 0-49%: #FFFFFF / 50-99%: #FFD700 / 100-149%: #FF8C00 / 150%+: #FF2020（0.5Hz 闪烁） |
| **位置** | P1：信息区最左侧；P2：信息区最右侧（镜像） |
| **背景** | 无独立背景，依赖信息区整体底板 #1A1A2E 90% |
| **对比度** | 白 on #1A1A2E: 15.4:1 / 黄: 12.5:1 / 橙: 8.1:1 / 红: 4.2:1（全部 ≥ AAA 7:1 除红为 AA） |

**动画规格**：

| 动画 | 属性 | 时长 | 缓动 | 触发 |
|------|------|------|------|------|
| 数字跳变 | Scale 1.0x → 1.3x → 1.0x | 0.15s | EaseOutBack | OnDamagePercentChanged |
| 颜色过渡 | Color 平滑变化 | 0.2s | ease-in-out | 危险等级阈值跨越 |
| 红色闪烁 | Opacity 100% ↔ 30% | 1.0s 周期（0.5Hz） | 方波 | 150%+ 持续 |

**高对比度变体**：字号增大至 84px；背景改为 #000000 95%；橙色调亮为 #FFAA40；红色调亮为 #FF4040。

**布局空间估算**：56px 字号下 "999+" 约占 160px 宽度。

### 3.2 专注值条 (Focus Bar)

| 属性 | 规格 |
|------|------|
| **尺寸** | 宽 ~140px，高 10px |
| **形状** | 硬边矩形（圆角 0px），圆角极小矩形 <3px per Art Bible §3.3 |
| **轨道色** | #333333 |
| **填充色** | 当前角色职业主色（#E84545 / #5EADF2 / #2ECC71） |
| **填充比例** | FocusPoints / UnlockThreshold，钳制显示至 1.0 |
| **位置** | P1：伤害%右侧，间隔 8px；P2：技能槽左侧，间隔 8px（镜像） |
| **阈值标记线** | 1px 宽垂直线，#E8E8F0，位于 UnlockThreshold 对应比例处 |
| **"MAX" 标签** | Exo 2 Medium 10px，#666666，居中显示在条上方或条内 |

**状态视觉映射**：

| 状态 | 填充色 | 脉动 | 附加效果 |
|------|--------|------|---------|
| 正常（0-80%） | 职业色 | 无 | — |
| 加速脉动（>80%） | 职业色（亮度正弦调制 ±15%） | 1Hz → 3Hz 线性插值 | 频率 = Lerp(1, 3, (ratio-0.8)/0.2) |
| 解锁瞬间 | #FFFFFF 闪白 | 无 | 0.1s 闪白 → 清空 → 剩余值重填 |
| 已满（MAX） | #666666（变灰） | 无 | 显示 "MAX" 文字 |

**脉动实现**：正弦波亮度调制，振幅 ±15%（Art Bible §7.3 原则 C 上限），频率从 1Hz 到 3Hz。

**对比度说明**：
- 法师蓝 #5EADF2 on #333333 ≈ 3.5:1（达标）
- 盗贼绿 #2ECC71 on #333333 ≈ 3.8:1（达标）
- 战士红 #E84545 on #333333 ≈ 2.6:1（**已知问题**，见 §6）

### 3.3 技能槽位组 (Skill Slots)

| 属性 | 规格 |
|------|------|
| **单槽尺寸** | 48×48px |
| **槽位间距** | 4px |
| **总宽** | 4×48 + 3×4 = 204px |
| **位置** | P1：专注值条右侧；P2：专注值条左侧（镜像） |
| **图标底板** | #2A2A3E（100% 不透明），圆角 4px（Art Bible §7.2） |
| **符号区域** | 24×24px 居中（Art Bible §7.2） |

**槽位状态视觉**：

| 状态 | 外观 | 动画 |
|------|------|------|
| 空 | #555555 轮廓（1px 实线）+ 按键提示文字（12px #E8E8F0） | 无 |
| 已装备 | 技能图标 on #2A2A3E 底板 + 稀有度边框（见 §2.4） | 两阶段装备动画（见下） |
| 执行中 | 整体亮度提升 + 稀有度色脉动边框（2Hz） | 持续脉动 |
| 被打断 | 全槽闪红 #FF2020 | 0.2s 线性闪光 → 恢复 |
| 不可用 | 底板不变，符号降为 #3A3A5C + 对角线斜杠 | 无 |

**装备动画（两阶段）**：

| 阶段 | 属性变化 | 时长 | 缓动 |
|------|---------|------|------|
| Phase 1 | Scale 0 → 1.2x | 0.05s | Linear |
| Phase 2 | Scale 1.2x → 1.0x + 稀有度色光晕闪烁 | 0.2s | Cubic ease-out |

总时长 0.25s。与 Art Bible §7.3 原则 A 一致（入场 ≤ 0.25s）。

**按键提示规格**：
- 字体：Exo 2 Medium 12px
- 颜色：#E8E8F0
- 强制大写
- P1：数字 "1" / "2" / "3" / "4"
- P2：可配置（手柄图标 / 数字 / 自定义键位）

### 3.4 比分区 (Score Area)

| 属性 | 规格 |
|------|------|
| **位置** | 屏幕顶部中央，水平居中 |
| **尺寸** | ~200×40px |
| **背景** | #1A1A2E 70% 半透明暗色条 |
| **边框** | 1px #3A3A5C 60%（底板分隔线风格） |
| **圆角** | 4px |
| **比分格式** | "[P1分] - [P2分]"（如 "1 - 0"） |
| **比分字体** | Exo 2 SemiBold 28px，#FFFFFF，tabular-nums |
| **比分字间距** | 1.1px (4%) |
| **回合格式** | "R[回合]/[总回合]"（如 "R2/3"） |
| **回合字体** | Exo 2 Regular 18px，#E8E8F0 |
| **回合字间距** | 0.7px (4%) |
| **更新行为** | 事件驱动（OnRoundEnd） |

**赛点标记**：

| 属性 | 规格 |
|------|------|
| **符号** | "●" |
| **字体** | Exo 2 Bold 28px |
| **颜色** | #FFD700 |
| **动画** | 亮度脉动 ±15%，1Hz 正弦波 |
| **触发条件** | 任一方 scores[i] == WinsNeeded - 1 |
| **位置** | 领先方分数旁（左侧或右侧） |

**安全边距**：距屏幕顶部 16px。

**对比度**：#FFFFFF on #1A1A2E 70%：
- 复合背景色 ≈ 70% × #1A1A2E + 30% × 战斗背景
- 最差情况（战斗背景最亮 #2A2A4E）：#FFFFFF on #1F1F3B ≈ 13.2:1
- 最佳情况（战斗背景 #1A1A2E）：15.4:1

### 3.5 KO 通知 (KO Notification)

| 属性 | 规格 |
|------|------|
| **文字** | "KO!" |
| **位置** | 屏幕正中央 |
| **字体** | Exo 2 Bold 84px |
| **填充色** | #FFFFFF |
| **描边** | 3px，胜者职业色（#E84545 / #5EADF2 / #2ECC71） |
| **投影** | 2px 模糊投影（Art Bible §7.5.4 系统大字允许） |
| **字间距** | 4.2px (5%) |

**动画序列**：

| 阶段 | 属性 | 时长 | 缓动 |
|------|------|------|------|
| 弹入 | Scale 0 → 1.5x → 1.0x | 0.3s | EaseOutBack |
| 保持 | Scale 1.0x，全不透明 | 0.5s | — |
| 淡出 | Opacity 100% → 0% | 0.3s | Cubic ease-out |
| **总时长** | | **~1.1s** | |

**触发条件**：击退系统 SignalKO(winnerPlayerSlot) → 游戏状态进入 BattleEnd。

**高对比度变体**：描边加粗至 6px；字号增大至 120px。

**对比度**：#FFFFFF on 任意战斗背景 + 3px 职业色描边 + 2px 投影 ≈ 远超 AAA 7:1。

### 3.6 边缘警告 (Edge Warning)

| 属性 | 规格 |
|------|------|
| **位置** | 屏幕四边，向内渐变覆盖 |
| **渐变区域宽度** | ~70px |
| **渐变方向** | 屏幕边缘（不透明）→ 屏幕内部（透明） |
| **颜色** | 橙 → 红：#FF8C00 → #FF2020 |
| **不透明度范围** | 0% → 40%（随角色与 Blast Zone 距离比例线性插值） |
| **触发条件** | 角色与 Blast Zone 距离 < 边缘警告阈值 |
| **更新频率** | 每帧 |
| **多人处理** | P1/P2 各自独立叠加（取最大不透明度渲染） |

**视觉实现**：使用径向渐变遮罩（Gradient Overlay），从屏幕对应边缘向内 70px 区域内线性插值。上下左右四条边缘独立计算，各自对应角色在该方向的 Blast Zone 距离。

**渲染层级**：在所有 HUD 元素之下，战斗层之上。半透明叠加不影响 HUD 信息可读性。

### 3.7 方向指示箭头 (Direction Indicator Arrow)

| 属性 | 规格 |
|------|------|

## 5. Animation Style Guide

### 5.1 缓动函数分配表

| 缓动函数 | 使用场景 | 原因 |
|----------|---------|------|
| **EaseOutBack** | 伤害%弹跳、KO 弹出 | 仅用于战斗核心冲击反馈。Back 缓动产生的「过冲-回弹」传达「被击中」的物理冲击感 |
| **Cubic ease-out** | 技能装备 Phase 2、KO 淡出、HUD 淡入、箭头出现、所有非弹性入场动画 | 默认缓动。快速到达目标 + 缓慢停止 = 「磁吸」感，与硬边几何语言一致（Art Bible §7.3） |
| **Linear** | 技能装备 Phase 1（0→1.2x）、解锁闪白、被打断闪红、颜色过渡中的插值 | 不需要缓动的线性状态变化 |
| **ease-in-out** | 伤害%颜色过渡 | 平滑过渡不跳变 |
| **正弦波 (Sine)** | 专注值脉动、赛点脉动、箭头脉动 | 循环动画的标准波形，振幅 ±15% |
| **Cubic ease-in** | HUD 淡出、面板关闭 | 从静止加速离开 |

### 5.2 时长标准

| 类别 | 标准时长 | 上限 | 来源 |
|------|---------|------|------|
| 入场动画 | 0.15-0.25s | 0.25s | Art Bible §7.3 原则 A |
| 退场动画 | 0.15s | 0.15s | Art Bible §7.3 原则 A |
| 状态变化闪光 | 0.1-0.2s | 0.2s | 即时反馈 |
| 循环/持续动画周期 | 0.33-2.0s（0.5Hz-3Hz） | — | Art Bible §7.3 原则 A |
| 颜色过渡 | 0.2s | 0.3s | 不超过 0.3s 避免延迟感知 |
| KO 总序列 | 1.1s | 1.5s | 含弹入 + 保持 + 淡出 |
| HUD 淡入/淡出 | 0.3s | 0.5s | battle-hud GDD Tuning Knobs |

### 5.3 脉动频率标准

| 元素 | 频率范围 | 说明 |
|------|---------|------|
| 专注值条（正常） | 0 Hz（静态） | 不脉动 |
| 专注值条（>80%） | 1.0 → 3.0 Hz | 线性插值，频率随填充比增加 |
| 技能槽执行中 | 2 Hz | 固定频率边框脉动 |
| 赛点标记 "●" | 1 Hz | 固定频率亮度脉动 |
| 方向箭头 | 1 Hz | 固定频率亮度脉动 |
| 稀有度微脉动（Rare） | ~0.2 Hz（5 秒周期） | 极微弱亮度波动 5% |

**光敏癫痫安全阈值**：所有脉动频率 ≤ 3Hz，远低于 6Hz 通用安全阈值（hud.md Accessibility 已覆盖）。

### 5.4 颜色过渡标准

| 过渡类型 | 时长 | 缓动 | 说明 |
|----------|------|------|------|
| 伤害%危险等级变色 | 0.2s | ease-in-out | 阈值跨越时触发 |
| 专注值解锁闪白 | 0.1s | Linear | 达到阈值瞬间 |
| 技能被打断闪红 | 0.2s | Linear | 被打断瞬间 |
| HUD 淡入 | 0.3s | Cubic ease-out | 进入 Countdown |
| HUD 淡出 | 0.3s | Cubic ease-in | 进入 Results |

### 5.5 减少动作模式 (Reduced Motion)

| 动画 | 默认行为 | 减少动作模式 | 理由 |
|------|---------|-------------|------|
| 伤害%弹跳 | Scale 1.0→1.3→1.0, EaseOutBack | **简化为 0.1s 淡入** | 弹跳不是信息传达必要手段 |
| KO 弹出 | Scale 0→1.5→1.0, EaseOutBack | **简化为 0.2s 淡入** | 弹出不是信息传达必要手段 |
| 颜色过渡 | 0.2s ease-in-out | **保留不变** | 颜色变化是核心信息通道 |
| 专注值脉动 | 正弦波 1-3Hz | **禁用脉动，保留填充量变化** | 脉动是增强信号 |
| 技能装备动画 | 两阶段 Scale | **简化为 0.1s 淡入** | 弹入不是信息传达必要手段 |
| 技能被打断闪红 | 0.2s Linear | **保留不变** | 打断反馈是关键战斗信息 |
| 边缘警告渐变 | 每帧更新 | **保留不变** | 位置信息，非装饰性动画 |
| 方向箭头脉动 | 1Hz 正弦波 | **禁用脉动，保留箭头显示** | 箭头位置是核心信息 |
| 赛点脉动 | 1Hz 正弦波 | **禁用脉动，保留标记显示** | 标记存在是核心信息 |
| HUD 淡入/淡出 | 0.3s | **保留不变** | 状态转换必要 |

**原则**（来源：Art Bible §7.5.5）：不提供完全关闭动画选项——状态变化无视觉回应会导致信息缺失。减少动作模式保留所有信息性动画（颜色变化、淡入淡出），移除所有装饰性动画（弹跳、脉动、过冲）。

### 6.2 已知问题：战士红专注值条对比度

**问题**：战士红 #E84545 on 轨道 #333333 的对比度约 2.6:1，低于 WCAG 3:1 大元素最低要求。

**影响分析**：
- 专注值条宽 140px、高 10px，在 1920×1080 下属于「大元素」（面积 > 36px 等效）
- 低对比度影响：在极端情况下（亮度环境过亮），战士玩家的专注值填充边界可能难以辨识
- 实际影响有限：专注值条位于固定位置，玩家知道在哪里找；填充量变化是连续动画，边界模糊不影响「进度感知」

**缓解措施**：
1. **阈值标记线**（#E8E8F0 on #333333 ≈ 8.5:1）提供绝对位置参考点
2. **"MAX" 文字标签**提供满值状态的明确信号
3. **脉动动画**（>80% 时）提供填充量的动态反馈通道
4. **高对比度模式**将填充色提升至 #F06060，对比度达到 3.5:1，完全达标
5. **未来优化选项**：在战士红填充条边缘添加 1px #FFFFFF 内描边（对比度问题完全消除）

#### 中央 70% 战斗区域验证

```
屏幕总宽: 1920px
P1 信息区: 540px（左下角）
P2 信息区: 540px（右下角）
安全边距: 16px × 2 = 32px
两侧信息区占比: (540 + 16) × 2 = 1112px ≈ 57.9%
```

**注意**：信息区位于底部角落，不是顶部横条。中央 70% 的约束（hud.md Layout Zones）指的是**战斗区域在垂直和水平方向上不被 HUD 遮挡**。

```
水平方向:
  P1 信息区距左边缘 16px，宽 540px，底部对齐
  P2 信息区距右边缘 16px，宽 540px，底部对齐
  中央无遮挡区域宽度: 1920 - 16 - 540 - 16 - 540 - 16 = 792px
  中央区域占比: 792/1920 = 41.25%（水平）

垂直方向:
  信息区高度 ~80px + 底部安全边距 12px = ~92px
  比分区高度 ~40px + 顶部安全边距 16px = ~56px
  中央无遮挡区域高度: 1080 - 56 - 92 = 932px
  中央区域占比: 932/1080 = 86.3%（垂直）
```

**中央可用战斗区域**: 最窄处 792×932px = 738,144px²，占屏幕面积 1920×1080 = 2,073,600px² 的 **35.6%**。

但 hud.md 定义的是「屏幕中央 70%」的矩形区域（~1344×756px）。由于底部信息区仅在角落（高 ~80px，且不跨越中央），实际上 **1344×756px 的中央矩形完全不被 HUD 遮挡**——底部信息区在 756px 线以下，比分区在 756px 线以上但位于顶部中央且高度仅 ~40px。

**结论**：中央 70% 战斗区域约束满足。HUD 元素全部位于屏幕边缘角落和顶部中央窄条，不影响中央战斗视野。
