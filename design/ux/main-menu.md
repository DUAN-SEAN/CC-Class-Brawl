## Purpose & Player Need

主菜单的唯一核心目标是让玩家用最少的操作进入战斗。这是一个本地多人派对格斗游戏——玩家启动游戏是因为想和朋友立刻打起来。

**玩家到达时想做的事**：开始一局对战。不是浏览菜单，不是调整设置，不是看故事。

**如果没有这个界面会怎样**：如果游戏直接进入角色选择，大多数情况下体验会更好。主菜单存在的唯一理由是提供一个"入口仪式感"和极少数非核心操作（设置、退出）的访问点。

**核心设计约束**：从主菜单到达角色选择界面的交互次数不得超过 1 次（单次按键）。这与游戏支柱「快速战斗」直接对齐。

**情感目标**：轻松、期待——像走进一个还没开场的擂台，等待朋友就位。不是紧张的，也不是无聊的——是"准备好了吗？走吧！"的感觉。

## Player Context on Arrival

**何时遇到**：每次启动游戏后的第一个界面。没有跳过机制——主菜单是每次游戏会话的固定起点。

**从哪里来**：游戏启动画面/引擎 Logo 之后。玩家刚刚双击了桌面图标或按了 Steam 的"开始游戏"。

**情绪状态**：社交性兴奋——朋友可能就在旁边，等着"快点开"。这不是一个需要冷静思考的界面，而是一个"让我进去"的冲动时刻。

**到达方式**：被游戏引导至此——玩家不是主动选择来到这里的，而是游戏流程的必经之站。

**身边环境**：本地多人场景——可能有 2 个手柄已连接，可能有人在等另一个朋友拿起第二个手柄。界面不应催促，但也不应该挡路。

## Navigation Position

主菜单是游戏导航树的**根节点**。它位于 `MenuScene` 中，是所有游戏流程的起点。

**层级定位**：`[根] → 主菜单`

从主菜单出发，玩家可以进入：
- 角色选择（核心路径 — 开始对战）
- 设置弹出层（覆盖在主菜单上）
- 操作指南弹出层（覆盖在主菜单上）
- 退出游戏（终止导航）

从结果界面选择"退出到菜单"是回到主菜单的唯一路径。

### 入口

| 入口来源 | 触发方式 | 玩家携带的上下文 |
|---------|---------|----------------|

### 出口

| 目的地 | 触发方式 | 备注 |
|-------|---------|------|
| 角色选择 | 选中"开始对战"并确认 | 场景切换 MenuScene → GameScene，目标 < 2s |

## Layout Specification

### Information Hierarchy

1. **"开始对战"** — 绝对最高优先级。玩家来这里就是要做这件事。
2. **游戏标题** — 品牌标识，但不如进入战斗重要（玩家已经知道在玩什么）。
3. **设置 / 操作指南** — 低优先级，偶尔需要的次要操作。
4. **退出** — 最低优先级，极少使用。
5. **版本号/版权** — 信息性，不需要被注意到除非主动寻找。

### Layout Zones

- **顶部栏**（屏幕上方 ~10%）— 次要操作区，小字号 UI中性灰 (#3A3A5C)
- **中央焦点区**（屏幕中央 40-60%）— "开始对战"按钮，职业色或白色高亮，最大视觉权重
- **底部氛围区**（屏幕下方 ~25%）— 游戏标题、版本号，低对比度装饰性信息
- **背景层** — 暗底 #1A1A2E + 呼吸灯几何动画（遵循美术圣经 §2.1 战斗大厅氛围）

### Component Inventory

| 区域 | 组件 | 类型 | 内容 | 交互 | 备注 |
|------|------|------|------|------|------|
| 顶部栏 | 设置按钮 | 按钮 | "设置" | 可点击 | 小字号，低调 |
| 顶部栏 | 操作指南按钮 | 按钮 | "操作指南" | 可点击 | 小字号，低调 |
| 顶部栏 | 退出按钮 | 按钮 | "退出" | 可点击 | 小字号，低调 |
| 中央焦点区 | 开始对战 | 大按钮/CTA | "开始对战" + 输入提示文字 | 核心交互 | 最大视觉权重，手柄默认焦点 |
| 底部氛围区 | 游戏标题 | 文字/Logo | "职业对决 CLASS BRAWL" | 无 | 装饰性，低对比度 |
| 底部氛围区 | 版本号 | 文字 | "v0.1.0" | 无 | 右下角，极小字号 |
| 背景层 | 背景动画 | 视觉装饰 | 几何形状呼吸灯动画 | 无 | 美术圣经 §2.1 呼吸灯环境光 |

## States & Variants

| 状态/变体 | 触发条件 | 界面变化 |
|----------|---------|---------|
| **启动淡入** | 游戏启动，Logo 播放完毕 | 从纯黑淡入到主菜单，约 0.5-1s。动画元素渐次出现：先背景 → 再标题 → 最后菜单选项和"开始对战"。 |
| **默认状态** | 淡入完成 | 背景呼吸灯动画循环播放。"开始对战"按钮有微弱的职业色脉动效果，吸引注意力。所有菜单选项可交互。 |
| **加载过渡** | 选择"开始对战"后 | "开始对战"按钮变为加载状态（进度指示或加载文字）。背景保持不变或加速动画。超时 5s 显示错误提示（与 game-state-management GDD 的 SceneLoadTimeout 一致）。 |
| **退出确认** | 选择"退出" | 弹出居中确认弹窗："确定退出游戏？" + "确认" / "取消"。弹窗外区域半透明暗色遮罩。默认焦点在"取消"（防止误操作）。 |

MVP 无平台变体（仅 PC），无玩家进度状态（无存档/进度系统）。

## Interaction Map

**输入方式**：键盘/鼠标 + 手柄（完整支持），主输入为手柄。

| 组件 | 动作 | 手柄输入 | 键盘/鼠标输入 | 即时反馈 | 结果 |
|------|------|---------|--------------|---------|------|
| 开始对战 | 确认 | A / Start | Enter / 左键点击 | 按钮缩放 + 音效 | 进入加载过渡 → 角色选择 |
| 设置 | 确认 | A | Enter / 左键点击 | 按钮高亮 + 音效 | 打开设置弹出层 |
| 操作指南 | 确认 | A | Enter / 左键点击 | 按钮高亮 + 音效 | 打开操作指南弹出层 |
| 退出 | 确认 | A | Enter / 左键点击 | 按钮高亮 + 音效 | 打开退出确认弹窗 |
| 确认退出 | 确认 | A | Enter / 左键点击 | 按钮缩放 + 音效 | 退出游戏 |
| 取消退出 | 确认 / 取消 | B / Escape | Escape | 弹窗关闭 + 音效 | 回到默认状态 |
| 任意菜单项 | 导航 | 方向键 / 左摇杆 | Tab / 方向键 / 鼠标移动 | 焦点指示器移动 + 音效 | 切换焦点到目标元素 |

**焦点起始位置**：默认聚焦在"开始对战"按钮（最高优先级操作）。

**焦点导航顺序**：开始对战 → 设置 → 操作指南 → 退出（顶部栏从左到右），循环。

**弹出层焦点**：弹出层打开时焦点锁定在弹出层内。关闭后焦点回到触发弹出层的原按钮。

## Events Fired

| 玩家操作 | 触发事件 | 载荷/数据 | 备注 |
|---------|---------|----------|------|
| 选择"开始对战" | `OnMainMenuStartBattle` | 无 | 触发 GameState 从 MainMenu → CharacterSelect |
| 打开设置弹出层 | `OnMainMenuSettingsOpened` | 无 | 遥测事件 |
| 关闭设置弹出层 | `OnMainMenuSettingsClosed` | `settings_changed: bool` | 遥测 — 是否修改了设置 |
| 打开操作指南 | `OnMainMenuHowToPlayOpened` | 无 | 遥测事件 |
| 关闭操作指南 | `OnMainMenuHowToPlayClosed` | 无 | 遥测事件 |
| 打开退出确认 | `OnMainMenuQuitRequested` | 无 | 遥测事件 |
| 确认退出 | `OnMainMenuQuitConfirmed` | `session_duration: float` | 遥测 + 游戏退出。**修改持久状态** |
| 取消退出 | 无事件 | — | 取消操作不需要事件 |

**标记**：`OnMainMenuQuitConfirmed` 是唯一修改持久状态的操作（终止游戏进程）。`OnMainMenuStartBattle` 触发场景加载。

## Transitions & Animations

### 屏幕进入过渡（启动淡入 → 默认状态）
- **效果**：淡入 + 渐次元素出现
- **时长**：0.5-1 秒
- **顺序**：背景渐显 → 标题渐显 → 菜单选项渐显 → "开始对战"按钮最终高亮
- **曲线**：Ease Out（快速开始，平缓结束）

### 屏幕退出过渡（默认状态 → 角色选择）
- **效果**：淡出到黑屏
- **时长**：0.3-0.5 秒（符合 GDD 约束的 <2s 总场景切换时间）
- **曲线**：Ease In（平缓开始，快速结束）
- **注意**：淡出完成后触发场景异步加载，加载期间可显示简化 Loading 提示

### 弹出层过渡（设置 / 操作指南）
- **打开**：弹出层从屏幕中央缩放出现（0.1s），伴随半透明黑色遮罩渐显
- **关闭**：弹出层缩放消失（0.1s），遮罩渐隐

### 退出确认过渡
- **打开/关闭**：与普通弹出层相同

### 状态变化动画
- **"开始对战"按钮**：微弱脉动效果（不缩放，仅亮度或职业色饱和度变化），周期约 2 秒
- **背景呼吸灯**：遵循美术圣经 §2.1 — 极缓慢的明暗周期（约 4 秒），暖色调（色温 4200K）
- **焦点指示器**：硬边几何形状（矩形/菱形），跟随焦点移动（0.05s 快速过渡）

### 减少动作模式（无障碍）
- 可通过设置选项禁用所有非必要动画，仅保留必要状态变化
- 启用时，脉动效果和背景呼吸灯停止，仅保留焦点指示器

## Data Requirements

| 数据 | 来源系统 | 读/写 | 备注 |
|------|---------|-------|------|
| 手柄连接状态 | Input System | 读 | 检测已连接的手柄数量，用于设置中的控制配置 |
| 游戏设置（音量/控制/画面） | Settings System | 读 + 写 | 设置弹出层读取当前值，修改后写回持久存储 |
| 游戏版本号 | Build Config | 读 | 用于版本号显示 |
| 语言偏好 | Settings System | 读 | 用于界面文本本地化（如有） |

**遥测数据**（只写）：
- `OnMainMenuSettingsOpened/HowToPlayOpened` — 用于分析玩家行为
- `OnMainMenuQuitConfirmed` + 会话时长 — 用于分析游戏会话长度

**架构关注点**：无。主菜单仅读取和写入设置，不管理游戏状态。游戏状态由 GameState Management 系统管理，主菜单仅响应状态变化。

## Accessibility

**注**：项目暂未定义无障碍等级文档（`design/accessibility-requirements.md`）。本规格列出基础无障碍考虑事项，建议后续正式定义无障碍等级后再完善。

| 需求项 | 实现方式 | 状态 |
|-------|---------|------|
| **键盘全导航** | 所有交互元素可通过 Tab/方向键访问 | ✓ 已覆盖（交互图已定义） |
| **手柄全导航** | 所有交互元素可通过方向键访问，循环导航 | ✓ 已覆盖（交互图已定义） |
| **焦点可见性** | 焦点指示器使用硬边几何形状 + 高对比度描边 | ✓ 已覆盖 |
| **高对比度模式** | 设置中提供高对比度选项（调高文字亮度） | 建议添加 |
| **文字缩放** | 设置中提供字体大小调整（标准/大/特大） | 建议添加 |
| **减少动作模式** | 设置中提供禁用非必要动画的选项 | ✓ 已覆盖（过渡动画章节） |
| **屏幕阅读器** | UI 元素标签提供，但未验证 | 待验证 |
| **色盲安全** | 关键信息不依赖单一颜色（焦点指示器有形状） | ✓ 已覆盖 |
| **色温调整** | 设置中提供"降低色温"选项（减少对光敏感用户的刺激） | 建议添加 |

## Localization Considerations

| 文本元素 | 最大中文字符数 | 预计英文字符数 | 扩展风险 | 备注 |
|---------|--------------|--------------|---------|------|
| "开始对战" | 4 | ~12-15 | 中 | "Start Battle" / "Press Start" — 需预留空间 |
| "设置" | 2 | ~8 | 低 | "Settings" — 不会超出布局 |
| "操作指南" | 4 | ~12 | 中 | "How to Play" — 需预留空间 |
| "退出" | 2 | ~6 | 低 | "Quit" — 不会超出布局 |
| "职业对决" | 4 | ~12-14 | 中 | "CLASS BRAWL" — 英文较长 |
| "按 A 开始" | 5 | ~12-15 | 中 | "Press A to Start" — 按键名可能本地化 |
| 版本号 | ~10 | ~10 | 无 | 格式不变 |
| 退出确认 | ~8 | ~25 | **高** | "确定退出游戏？" vs "Are you sure you want to quit?" — 需固定弹窗最小高度 |

**布局弹性要求**：
- 按钮容器宽度必须能容纳英文文本（约中文字符数的 3-4 倍）
- 退出确认弹窗高度固定，内容区域自动换行
- 顶部栏三个次要按钮采用等宽布局或弹性布局，避免小尺寸屏幕上拥挤

**字体选择建议**：
- UI 使用无衬线字体，支持中文和拉丁字符集
- 字号以中文为基准，英文不小于中文字号的 0.8 倍

## Acceptance Criteria

- [ ] 主菜单在游戏启动后 1 秒内完全显示并接受输入
- [ ] "开始对战"按钮在默认状态下聚焦，按 A/Enter 后 2 秒内进入角色选择界面
- [ ] 键盘 Tab 键或手柄方向键能依次访问所有菜单项，焦点指示器清晰可见
- [ ] 选择"退出"后显示确认弹窗，默认焦点在"取消"选项
- [ ] 所有交互元素在没有鼠标悬停时也能通过键盘/手柄操作（无仅悬浮交互）
- [ ] 按 Escape（键盘）或 B（手柄）能关闭任何弹出层，焦点回到触发弹出层的原按钮
- [ ] 加载超时（5 秒）时显示错误提示，不卡死在加载状态

## Open Questions

1. **玩家旅程文档缺失** — `design/player-journey.md` 不存在。本规格的"玩家到达时的上下文"章节基于游戏概念和游戏支柱做了假设，建议后续创建玩家旅程文档来验证和补充这些假设。模板位于 `.claude/docs/templates/player-journey.md`。

2. **无障碍等级未定义** — `design/accessibility-requirements.md` 不存在。本规格列出了基础无障碍考虑事项，但未验证是否符合目标平台（PC）的期望等级。建议定义无障碍等级后再完善。

3. **设置和操作指南弹出层的设计** — 本规格仅定义了它们作为弹出层的存在，但未详细设计其内部布局和交互。这些需要单独的 UX 规格（`design/ux/settings.md` 和 `design/ux/how-to-play.md`）。

4. **背景动画的具体实现** — 美术圣经定义了呼吸灯效果（暖色调 4200K，4 秒周期），但本规格未详细描述具体的几何元素和动画曲线。这是美术团队的决策。

5. **本地化目标语言** — 本规格假设英文是目标语言，但未确认是否支持其他语言（如日文、韩文、俄文等）。这些语言可能有不同的字符宽度和排版需求。
