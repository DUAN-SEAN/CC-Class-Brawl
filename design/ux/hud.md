## HUD Philosophy

**极少但存在** — 只有战斗决策必需的信息始终可见，其他信息通过动画和颜色变化在余光中传递。

HUD 不应该被"阅读"——它应该被"感知"。当一切运转正常时，玩家甚至不会意识到自己在读 HUD：百分比的颜色变化触发"该防守了"的直觉，专注值条的脉动速度传递"快解锁了"的紧迫感，技能槽的亮起带来"新武器到手"的兴奋。

**设计铁律**：
- 屏幕中央 70% 永远不被 HUD 遮挡——这是角色和战斗的舞台
- 所有信息必须能在 0.5 秒内被余光感知，不需要停顿阅读
- 动画服务于信息传达，不装饰——每个动画都对应一个游戏事件

**与美术圣经的对齐**：
- UI 使用独立硬边几何语言（美术圣经 §3.3），不与环境或角色风格融合
- 色彩遵循语义色彩系统（美术圣经 §4.2）：职业色 = 身份 + 所有权
- 能量阶段渐增通过角色视觉效果表达，不通过 HUD 元素膨胀

## Information Architecture

### Full Information Inventory

| # | 信息 | 来源系统 | 更新频率 |
|---|------|---------|---------|
| 1 | P1 伤害百分比（数字 + 颜色） | 伤害计算系统 | 事件驱动（命中时） |
| 2 | P2 伤害百分比（数字 + 颜色） | 伤害计算系统 | 事件驱动（命中时） |
| 3 | P1 专注值进度条 | 专注值系统 | 事件驱动（积攒时） |
| 4 | P2 专注值进度条 | 专注值系统 | 事件驱动（积攒时） |
| 5 | P1 已装备技能槽位 ×4 | 技能装备管理 | 事件驱动（解锁时） |
| 6 | P2 已装备技能槽位 ×4 | 技能装备管理 | 事件驱动（解锁时） |
| 7 | 比分（P1-P2） | 对局管理系统 | 事件驱动（局结束时） |
| 8 | 回合序号 | 对局管理系统 | 事件驱动（局结束时） |
| 9 | 赛点标记 | 对局管理系统 | 计算得出 |
| 10 | KO 通知文字 | 击退系统 | 事件驱动（KO 时） |
| 11 | 边缘警告渐变 | 场地系统 + 3C 系统 | 每帧查询（接近 Blast Zone 时） |
| 12 | 方向指示箭头 | 场地系统 + 3C 系统 | 每帧查询（超出摄像机边界时） |

### Categorization

所有 9 项信息分类为 **Must Show**（始终可见）。

**理由**：这些信息数量有限（9 项），且都是实时战斗决策的关键输入。伤害百分比决定攻防策略，专注值进度决定进攻节奏，技能槽位决定可用招式，比分决定比赛紧迫度。隐藏任何一项都会导致信息不对称。

**密度控制**：通过位置和尺寸分级（非显隐分级）来控制视觉密度——伤害百分比最大最醒目，比分最小最安静。

## Layout Zones

**基准分辨率**：1920×1080（Scale With Screen Size 自适应）

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│                     [ 1 - 0  R2/3 ]                             │  ← 比分区 (顶部中央)
│                                                                  │
│                                                                  │
│                                                                  │
│                战斗区域（中央 70% 无 HUD）                         │
│                                                                  │
│                                                                  │
│                                                                  │
│  42%  ████████░░  [■□□□]                     P2    [□■□□]  28%   │  ← P1 左下 / P2 右下
│  P1              [按键]                        [按键]             │
└──────────────────────────────────────────────────────────────────┘
```

### 区域定义

| 区域 | 位置 | 尺寸（1920×1080 基准） | 用途 |
|------|------|----------------------|------|
| **比分区** | 顶部中央 | ~200×40px | 比分 + 回合序号 + 赛点标记 |
| **P1 信息区** | 左下角 | ~350×80px | P1 伤害% + 专注值条 + 技能槽 |
| **P2 信息区** | 右下角 | ~350×80px（镜像） | P2 技能槽 + 专注值条 + 伤害% |
| **战斗区域** | 屏幕中央 70% | ~1344×756px | 零 HUD 元素 |

### 安全边距

- P1/P2 信息区距屏幕边缘：16px（水平），12px（垂直）
- 比分区距顶部：16px

### Visual Budget

| 指标 | 上限 | 说明 |
|------|------|------|
| 渲染开销 | < 0.8ms/帧（帧预算 16.6ms 的 5%） | GDD 约束 |
| 常驻元素（Battle 状态） | 最多 14 个 | P1/P2 各：1 伤害% + 1 专注值条 + 4 技能槽位 = 12；+ 1 比分区 + 1 回合文字 |
| 上下文元素（同时触发） | 最多 6 个 | 2 个边缘警告（P1+P2）+ 2 个方向箭头 + 1 个 KO 通知 + 1 个赛点标记 |
| 屏幕占比（HUD 总面积） | < 15% | 不含中央战斗区域 |
| 同时动画数 | 最多 4 个 | 避免 GPU/CPU 动画队列积压 |

## HUD Elements

### 1. 伤害百分比 (Damage Percent)

| 属性 | 规格 |
|------|------|
| **类别** | Must Show — 始终可见 |
| **视觉形式** | 大号数字 + "%" 后缀 |
| **字号** | 48-64px（从 2 米外可读） |
| **颜色编码** | 0-49%: 白 `#FFFFFF` / 50-99%: 黄 `#FFD700` / 100-149%: 橙 `#FF8C00` / 150%+: 红闪 `#FF2020` |
| **更新行为** | 事件驱动（`OnDamagePercentChanged`） |
| **动画** | 缩放弹跳 1.0x→1.3x→1.0x（0.15s，EaseOutBack）；颜色过渡 0.2s |
| **极端值** | >999 显示 "999+"；负数钳制为 0% |

**P1 位置**：信息区最左侧
**P2 位置**：信息区最右侧（镜像对称）

### 2. 专注值进度条 (Focus Bar)

| 属性 | 规格 |
|------|------|
| **类别** | Must Show — 始终可见 |
| **视觉形式** | 水平进度条 |
| **尺寸** | 宽 ~140px，高 8-12px |
| **颜色** | 填充色 = 职业主色；背景 = 暗灰 `#333333` |
| **更新行为** | 事件驱动（`OnFocusChanged`） |
| **脉动** | >80% 时脉动加速（1Hz→3Hz）；达到上限时变灰 + "MAX" |
| **解锁动画** | 闪白 0.1s → 清空 → 剩余值重新填充 |
| **阈值标记线** | 垂直细线标记当前 `UnlockThreshold` 位置 |

**P1 位置**：伤害%右侧
**P2 位置**：技能槽左侧（镜像对称）

### 3. 技能槽位组 (Skill Slots)

| 属性 | 规格 |
|------|------|
| **类别** | Must Show — 始终可见 |
| **视觉形式** | 4 个正方形槽位横向排列 |
| **尺寸** | 每个 48×48px，间距 4px |
| **空槽位** | 灰色半透明轮廓 `#555555` + 按键提示（12px） |
| **已装备** | 技能图标 + 稀有度边框（白 `#4488FF` / 紫 `#8844CC` / 金 `#FFB800`） |
| **执行中** | 高亮 + 脉动边框（2Hz） |
| **被打断** | 短暂闪红 0.2s |
| **装备动画** | 弹入 0→1.2x→1.0x（0.25s，EaseOutBack）+ 稀有度色光晕 |

**P1 位置**：专注值条右侧
**P2 位置**：专注值条左侧（镜像对称）

### 4. 比分区 (Score Area)

| 属性 | 规格 |
|------|------|
| **类别** | Must Show — 始终可见 |
| **视觉形式** | 文字 + 半透明暗色背景条 |
| **字号** | 24-32px（中等，不喧宾夺主） |
| **颜色** | 白色文字 `#FFFFFF` |
| **显示格式** | "[P1分] - [P2分]  R[回合]/[总回合]"（如 "1 - 0  R2/3"） |
| **赛点标记** | 领先方分数旁显示 "●"（黄色脉动） |
| **更新行为** | 事件驱动（`OnRoundEnd`） |

### 5. KO 通知 (KO Notification)

| 属性 | 规格 |
|------|------|
| **类别** | Contextual — 仅在 KO 发生时显示 |
| **视觉形式** | 大号 "KO!" 文字 + 缩放弹出动画 |
| **位置** | 屏幕中央（短暂覆盖战斗区域，约 0.5-1 秒） |
| **字号** | 72-96px（全屏最大文字） |
| **颜色** | 白色 `#FFFFFF` + 被击中方职业色描边 |
| **触发条件** | 击退系统 `SignalKO(winnerPlayerSlot)` → 游戏状态进入 BattleEnd |
| **动画** | 缩放弹出 0→1.5x→1.0x（0.3s，EaseOutBack）→ 保持 0.5s → 淡出 0.3s |
| **数据来源** | 击退系统 → `OnKO(winnerIndex)` 事件 |

### 6. 边缘警告 (Edge Warning)

| 属性 | 规格 |
|------|------|
| **类别** | Contextual — 角色接近 Blast Zone 时显示 |
| **视觉形式** | 屏幕四边渐变红色/橙色叠加层 |
| **位置** | 屏幕边缘，向内渐变（边缘不透明→内部透明） |
| **宽度** | 渐变区域约 60-80px |
| **颜色** | 橙红渐变 `#FF8C00` → `#FF2020`，不透明度随距离比例增加（0%→40%） |
| **触发条件** | 角色与 Blast Zone 边界距离 < 边缘警告阈值 |
| **更新行为** | 每帧查询角色位置和 Blast Zone 数据 |
| **数据来源** | 场地系统 → `IArenaDataProvider.GetBlastZone()`；3C 系统 → 角色位置 |
| **多人处理** | P1/P2 各自独立的边缘警告，叠加显示（最危险的边缘优先渲染） |

### 7. 方向指示箭头 (Direction Indicator Arrow)

| 属性 | 规格 |
|------|------|
| **类别** | Contextual — 角色超出摄像机边界时显示 |
| **视觉形式** | 硬边几何箭头（三角形）+ 玩家编号标识 |
| **位置** | 屏幕边缘，指向角色偏离方向（上/下/左/右） |
| **尺寸** | 箭头约 24×24px |
| **颜色** | 对应玩家职业色 |
| **触发条件** | 角色位置超出摄像机边界（`GetCameraBounds()`） |
| **更新行为** | 每帧查询摄像机边界和角色位置 |
| **数据来源** | 场地系统 → `IArenaDataProvider.GetCameraBounds()`；3C 系统 → 角色位置 |
| **动画** | 箭头脉动（1Hz 亮度调制），随角色距离屏幕边缘远近调整不透明度 |

## Dynamic Behaviors

### HUD 可见性状态机

| 游戏状态 | HUD 行为 | 过渡 |
|---------|---------|------|
| MainMenu / CharacterSelect / MatchLoading | 隐藏 | — |
| Countdown | 淡入（0.3s） | 显示初始值（0%、空槽、0-0） |
| Battle | 可见 | 持续响应事件更新；边缘警告和方向箭头按条件显示 |
| BattleEnd | 冻结 + KO 通知 | 保持最终状态；显示 "KO!" 弹出动画（0.3s 弹入 + 0.5s 保持 + 0.3s 淡出） |
| Results | 淡出（0.3s） | — |

### 信息更新动画规范

| 动画 | 持续时间 | 缓动函数 | 触发事件 |
|------|---------|---------|---------|
| 百分比弹跳 | 0.15s | EaseOutBack | `OnDamagePercentChanged` |
| 颜色过渡 | 0.2s | EaseInOut | 颜色阈值跨越 |
| 进度条更新 | 即时 | — | `OnFocusChanged` |
| 解锁闪白 | 0.1s | Linear | `OnFocusReady` |
| 技能弹入 | 0.25s | EaseOutBack | `OnSkillEquipped` |
| 槽位闪红 | 0.2s | Linear | 技能被打断 |
| KO 弹出 | 0.3s 弹入 + 0.5s 保持 + 0.3s 淡出 | EaseOutBack | `SignalKO` (BattleEnd) |
| 边缘警告 | 每帧更新 | — | 角色接近 Blast Zone |
| 方向箭头 | 每帧更新 + 1Hz 脉动 | — | 角色超出摄像机边界 |

### 能量阶段视觉变化

战斗中 HUD 不会随能量阶段变化而膨胀，但以下行为与游戏能量阶段相关：
- **专注值脉动频率** 随专注值接近满而加速（1Hz→3Hz）
- **伤害%颜色** 随百分比增长从白→黄→橙→红闪
- **技能槽位** 随解锁逐个从空变亮

### 上游系统停止响应时

- 百分比/进度条冻结在最后值 + 5 秒后显示 "?" 过期标记

### Tuning Knobs

所有 HUD 可调参数定义在 `design/gdd/battle-hud.md` Tuning Knobs 章节（共 10 项）。关键参数：

| 旋钮 | 默认值 | 影响的 UX 属性 |
|------|--------|--------------|
| DamageNumberBounceScale | 1.3 | 伤害%弹跳幅度 |
| DamageNumberBounceDuration | 0.15s | 伤害%弹跳时长 |
| FocusPulseMinFrequency | 1.0 Hz | 专注值基础脉动频率 |
| FocusPulseMaxFrequency | 3.0 Hz | 专注值接近满时脉动频率 |
| FocusPulseThreshold | 0.8 | 开始加速脉动的填充比例 |
| SkillSlotSize | 48px | 技能槽位尺寸 |
| SkillEquipAnimDuration | 0.25s | 技能装备弹入动画时长 |
| HudFadeInDuration | 0.3s | HUD 淡入时长 |
| HudFadeOutDuration | 0.3s | HUD 淡出时长 |
| DataStaleTimeout | 5.0s | 数据过期标记超时 |

## Platform & Input Variants

### 平台变体

MVP 仅 PC（1920×1080 基准）。未来控制台/移动需要：

| 平台 | 预期变化 | 优先级 |
|------|---------|-------|
| PC（当前） | 基准设计 | MVP |
| 16:10 显示器 | Canvas Scaler 自适应，左右微窄边 | — |
| 4:3 显示器 | 信息区压缩至最小尺寸，优先保证伤害%可读 | — |

### 输入变体

| 输入方式 | 按键提示 | 显示内容 |
|---------|---------|---------|
| 手柄 | P1: 预设按键图标 / P2: 预设按键图标 | 技能槽位显示手柄按键 |
| 键盘 | P1: "1/2/3/4" / P2: 可配置 | 技能槽位显示数字 |

**注意**（battle-hud GDD 开放问题 #2）：P2 的技能键提示显示方式待定，需要与 Input System 配置协调。

## Accessibility

| 需求项 | 实现方式 | 状态 |
|-------|---------|------|
| **颜色非唯一信息渠道** | 伤害%数字本身携带信息（颜色是加速器，非唯一信号） | ✓ 已覆盖 |
| **色盲安全** | 百分比数字 + 颜色双重编码；技能稀有度用边框粗细区分 | ✓ 已覆盖 |
| **脉动频率限制** | 专注值脉动最快 3Hz，低于光敏癫痫安全阈值（6Hz） | ✓ 已覆盖 |
| **技能槽按键提示** | 最小 12px 可读 | ✓ 已覆盖 |
| **高对比度模式** | 建议添加（增强百分比和进度条对比度） | 建议添加 |
| **减少动作模式** | 建议添加（禁用弹跳和脉动动画，保留颜色变化） | 建议添加 |
