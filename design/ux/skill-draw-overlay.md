## Purpose & Player Need

技能抽取悬浮 UI 是游戏核心独特机制的呈现层——让玩家在专注值满时快速从 3 个随机技能中选择一个，且**不中断战斗节奏**。

**玩家到达时想做的事**：尽快看到抽到了什么技能，快速做出选择，回到战斗。选择本身不是深度策略思考——是"这个看起来更有趣"的直觉判断。

**核心设计约束**：
- 选择过程不暂停游戏，角色仍可移动（GDD 约定）
- 从抽取触发到完成选择，目标 < 3 秒（5 秒超时保底）
- 输入被 UI 拦截：方向键和确认键用于选择，不传递给战斗
- 两个玩家可以同时触发抽取，各自独立

**情感目标**：
- 期待："我抽到了什么？"
- 惊喜：稀有度颜色闪烁的瞬间反馈
- 即时策略转向："我现在该怎么用这个技能？"
- 派对感："你看到了吗？我抽到金色那个！"

**与游戏支柱对齐**：Pillar 2（每局都是新故事）— 抽取是多样性的引擎。Pillar 4（快速战斗）— 选择不中断战斗。

## Player Context on Arrival

**何时遇到**：战斗中，专注值达到解锁阈值时自动触发。

**从哪里来**：从战斗中正常操作而来——玩家刚刚命中对手或被命中，专注值攒满了。

**情绪状态**：兴奋 + 紧迫 — "快解锁了！"的期待感在专注值 80% 时就已经建立（进度条脉动加速），到达阈值的那一刻是高潮。同时有紧迫感——对手仍在攻击，不能犹豫太久。

**到达方式**：被游戏事件触发，非玩家主动请求。

**特殊情况**：如果两个玩家同一帧都触发抽取，各自独立显示选择 UI，互不干扰。

## Navigation Position

技能抽取 UI 不是导航树的一部分——它是一个战斗中的**模式覆盖层**。

**层级定位**：`战斗 HUD → [技能抽取悬浮层]`（覆盖在战斗 HUD 之上）

弹出时：
- 战斗 HUD 保持可见（位于悬浮层下方）
- 角色和场地保持可见（悬浮层半透明）
- 游戏不暂停

## Entry & Exit Points

### 入口

| 入口来源 | 触发方式 | 玩家携带的上下文 |
|---------|---------|----------------|
| 专注值系统 | `OnDrawReady` 事件 | 候选技能列表（3 个 SkillData） |

### 出口

| 目的地 | 触发方式 | 备注 |
|-------|---------|------|
| 返回战斗 | 玩家确认选择（A 键） | 选中技能飞向 HUD 槽位 |

## Layout Specification

### Information Hierarchy

1. **3 张技能卡牌** — 最高优先级，这是选择的核心
2. **超时倒计时** — 次要但重要，传达紧迫感
3. **当前高亮指示** — 次要，让玩家知道焦点在哪张卡牌上
4. **操作提示** — 最低，"← → 选择，A 确认"

### Layout Zones

- **卡牌区域** — 屏幕下半部分中央，3 张卡牌横向排列
- **倒计时区域** — 卡牌区域下方或中心
- **背景遮罩** — 卡牌区域周围的半透明暗色遮罩（不遮挡角色上方）

### Component Inventory

| 区域 | 组件 | 类型 | 内容 | 交互 | 备注 |
|------|------|------|------|------|------|
| 卡牌区域 | 技能卡牌 ×3 | 卡牌 | 技能图标 + 技能名称 + 稀有度边框 | 方向键切换焦点 | 中央卡牌略大 |
| 卡牌区域 | 高亮卡牌 | 卡牌（激活态） | 放大 + 光晕 + 边框加粗 | 确认键选择 | 视觉突出 |
| 倒计时区域 | 圆形进度条 | 进度指示 | 5 秒倒计时 | 无交互 | 最后 1 秒加速闪烁 |
| 背景遮罩 | 半透明遮罩 | 视觉 | 暗色半透明 | 无交互 | 仅在卡牌区域，不遮挡角色上半身 |

## States & Variants

| 状态/变体 | 触发条件 | 界面变化 |
|----------|---------|---------|
| **弹入动画** | `OnDrawReady` 事件 | 3 张卡牌从屏幕边缘弹入（< 0.3s），半透明遮罩渐显 |
| **等待选择** | 卡牌完全显示 | 高亮默认在中间卡牌，倒计时开始（5 秒） |
| **切换高亮** | 玩家按方向键 | 高亮移动到相邻卡牌，循环 wrap |
| **超时警告** | 剩余 < 1 秒 | 倒计时加速闪烁，卡牌边框微弱脉动 |
| **超时自动选择** | 5 秒到期 | 自动选中第一个候选，播放低沉音效 |
| **确认选择** | 玩家按 A | 选中卡牌放大闪光 → 飞向 HUD 槽位 |
| **未选中淡出** | 选择完成 | 未选中的 2 张卡牌淡出（< 0.2s） |
| **稀有度全屏闪光** | 选择完成后 | Common: 蓝色微光 / Rare: 紫色闪光 / Epic: 金色爆发 + 全屏金框 |
| **双人同时** | 双方同帧触发 | 各自独立选择 UI，P1 偏左、P2 偏右 |
| **降级：2 选 1** | 牌池仅 2 个技能 | 仅显示 2 张卡牌 |
| **降级：自动选择** | 牌池仅 1 个技能 | 不显示选择 UI，直接完成 |

## Interaction Map

**输入方式**：手柄（主输入）+ 键盘。

**输入拦截**：选择 UI 激活时，方向键和确认键被 UI 拦截，不传递给战斗系统。摇杆移动不拦截。

| 组件 | 动作 | 手柄输入 | 键盘输入 | 即时反馈 | 结果 |
|------|------|---------|----------|---------|------|
| 技能卡牌 | 切换高亮 | 方向键 ←/→ | A/D 键 | 卡牌高亮移动 + "切换"音效 | 焦点移到相邻卡牌（循环） |
| 技能卡牌 | 确认选择 | A | Enter / 空格 | 卡牌放大 + "确认"音效 | 选中技能，触发飞行动画 |

**焦点起始位置**：中间卡牌（第 2 张）。

**焦点导航**：← 向左，→ 向右，循环（第 1 张按 ← 到第 3 张）。

**P1/P2 独立操作**：P1 和 P2 各自有自己的焦点和倒计时，互不干扰。

## Events Fired

| 玩家操作 | 触发事件 | 载荷/数据 | 备注 |
|---------|---------|----------|------|
| 切换高亮 | `OnDrawHover` | `CharacterId, CandidateIndex` | UI 层内部事件 + 音效 |
| 确认选择 | `OnSkillSelected` | `CharacterId, SkillData` | 触发装备流程 |
| 超时自动选择 | `OnSkillSelected` | `CharacterId, CandidateList[0]` | 与手动选择相同，不同音效 |

**下游事件链**：`OnSkillSelected` → 技能装备管理 `OnSkillDrawn` → 战斗 HUD 更新 + 能量视觉特效。

## Transitions & Animations

### 弹入过渡（进入）
- **效果**：3 张卡牌从屏幕底部边缘弹入（< 0.3s），伴随半透明遮罩渐显
- **音效**：`OnDrawReady` — "开箱"音效（能量汇聚 + 卡牌弹出声）

### 确认选择过渡
- **效果**：选中卡牌放大闪光 → 飞向 HUD 技能槽位（< 0.5s 飞行动画）
- **音效**：`OnDrawSelect` — 清脆"叮" + 稀有度对应音调

### 未选中淡出
- **效果**：未选中的 2 张卡牌淡出（< 0.2s）

### 稀有度全屏闪光
- **Common**：蓝色微光（1 帧快速闪过）
- **Rare**：紫色闪光 + 短暂边框发光（0.3s）
- **Epic**：金色爆发 + 全屏金色边框（0.5s）

### 超时动画
- **倒计时圆形进度条**：持续减少
- **最后 1 秒**：加速闪烁 + 卡牌边框脉动
- **音效**：`OnDrawTimeout` — 低沉的"自动选择"音效

### 减少动作模式
- 禁用卡牌弹入动画和飞行动画，改为即时显示/消失
- 保留倒计时进度条（功能性动画）

## Data Requirements

| 数据 | 来源系统 | 读/写 | 备注 |
|------|---------|-------|------|
| 候选技能列表 | 技能抽取系统 | 读 | 1-3 个 SkillData |
| 技能图标 | SkillData.Icon | 读 | 每张卡牌显示 |
| 技能名称 | SkillData.DisplayName | 读 | 每张卡牌显示 |
| 稀有度 | SkillData.Rarity | 读 | 决定边框颜色和全屏闪光 |
| 剩余超时时间 | 技能抽取系统 | 读 | 倒计时进度条 |
| 玩家标识 | CharacterId | 读 | 区分 P1/P2 |

**架构关注点**：选择 UI 需要在 `OnDrawReady` 事件后立即渲染，渲染延迟不能影响超时计时（超时从事件发出时开始，不依赖 UI 渲染完成）。

## Accessibility

| 需求项 | 实现方式 | 状态 |
|-------|---------|------|
| **高亮可见性** | 高亮卡牌放大 + 光晕 + 边框加粗（形状+亮度双重信号） | ✓ 已覆盖 |
| **色盲安全** | 稀有度用边框粗细和图案差异区分（白线/紫虚线/金宽线+闪光） | ✓ 已覆盖 |
| **倒计时可读性** | 圆形进度条 + 最后 1 秒闪烁（非仅数字） | ✓ 已覆盖 |
| **减少动作模式** | 禁用弹入/飞行/闪光动画，保留倒计时 | ✓ 已覆盖 |
| **键盘全操作** | A/D 切换 + Enter 确认 | ✓ 已覆盖 |

## Localization Considerations

| 文本元素 | 最大中文字符数 | 预计英文字符数 | 扩展风险 | 备注 |
|---------|--------------|--------------|---------|------|
| 技能名称 | 3-6 | ~10-20 | **高** | 卡牌空间有限，需支持截断或缩小字号 |
| 操作提示 | ~10 | ~20 | 中 | "← → 选择  A 确认" |

**布局弹性要求**：
- 技能名称最大 2 行，超出截断 + "..."
- 卡牌宽度固定，名称区域自适应高度
- 稀有度标记不依赖文字（仅颜色+边框）

## Acceptance Criteria

- [ ] 抽取触发后 0.3 秒内卡牌完全显示
- [ ] 高亮默认在中间卡牌，方向键可循环切换
- [ ] 确认选择后 0.5 秒内卡牌飞向 HUD 槽位
- [ ] 5 秒超时自动选择第一个候选
- [ ] 选择 UI 激活期间，方向键不传递给战斗系统
- [ ] 选择 UI 激活期间，摇杆移动仍可操作角色
- [ ] 双人同时触发时，各自选择 UI 互不遮挡
- [ ] 稀有度视觉反馈与技能稀有度匹配（蓝/紫/金）

## Open Questions

1. **选择期间角色的精确行为** — 当前设计摇杆移动不被拦截，但角色是否能执行攻击、跳跃？GDD 标记为待定（Owner: 系统设计师）。建议 MVP 拦截所有战斗输入，仅允许移动。

2. **卡牌的视觉风格** — GDD 标记为待定（Owner: 艺术总监）。当前规格使用功能描述（图标+名称+边框），具体风格需要与 art bible 协调。建议几何风格硬边卡牌，与 UI 层语言统一。

3. **不暂停模式的公平性** — 选择期间对手可以趁机进攻。这是否会让"选技能"变成惩罚？需要原型验证（GDD 开放问题 #3）。

4. **双人的视觉优先级** — 当两个抽取 UI 同时出现时，如何避免视觉混乱？当前方案是 P1 偏左、P2 偏右，但需要实际验证。
