## 1. Visual Identity Statement

### 视觉铁律

**「能读懂，才允许炫」— 任何视觉元素，如果干扰了玩家在0.5秒内判断「谁在做什么、技能属于谁、能量到什么阶段」的能力，就必须被简化或移除。**

这条铁律服务于所有四个游戏支柱：
- **秒学秒玩**：可读 = 可学，看一眼就懂
- **每局都是新故事**：随机组合只有在能被读懂时才有趣，否则只是噪音
- **高手菜鸟都开心**：菜鸟觉得酷，高手能读取精确信息
- **快速战斗**：没有时间「习惯」混乱，必须一上来就清楚

### 支持原则

#### 原则1：形状即身份（Shape = Identity）

*设计测试*：当两个特效或角色可能混淆时，永远通过形状差异（而非颜色叠加或尺寸放大）来区分 — 战士是矩形/钝角、法师是三角/锐角、盗贼是菱形/尖角。

形状语言是不可违约的契约。战士永远不应该出现尖锐的三角形攻击特效，法师永远不应该有厚重的矩形弹道。

服务支柱：**秒学秒玩** + **高手菜鸟都开心**
- 菜鸟：看到三角形就知道是法师在攻击
- 高手：形状编码攻击类型（三角朝上=上段、朝下=下段、横置=横向）

#### 原则2：能量有形状，不是噪声（Energy Has Shape, Not Noise）

*设计测试*：当需要在「更多粒子」和「更少但更大/更清晰的元素」之间选择时，永远选后者 — 一个清晰缩放旋转的能量环比二十个随机飞散的小粒子更能传达「爆发」。

能量阶段的渐进表达：
- **早期（0-2个技能）**：角色边缘有与职业色一致的脉动光晕，频率与专注值进度同步。纯形状动画 — 缩放+透明度周期变化。零粒子。
- **中期（3-4个技能）**：角色周围出现与职业形状一致的环绕元素（战士有矩形碎片环绕、法师有三角形碎片环绕）。技能释放时，形状以职业色向外扩展。
- **后期（5+个技能）**：叠加物理能量表达 — 屏幕震动、闪光、形状碎裂。即使最混乱时刻，每个特效仍是可识别的几何形状。

服务支柱：**快速战斗** + **每局都是新故事**
- 快速战斗：能量阶段提供即时时间感知 — 看到对手脉动快了就知道专注值满了
- 每局都是新故事：不同技能组合产生不同环绕形状组合，视觉每局不一样

#### 原则3：一色一主，特效随主（One Color Per Master, Effects Follow）

*设计测试*：当任何特效的颜色归属可能产生歧义时，该特效必须使用施放者的职业主色 — 哪怕该技能的「主题色」与施放者不同（战士用了冰冻技能，特效仍然是战士的红色）。

职业色固定映射：
- 战士 = #E84545（红）
- 法师 = #5EADF2（蓝）
- 盗贼 = #2ECC71（绿）
- [其他职业待定]

每个颜色在深色背景上有最大对比度，彼此之间色相间隔大于90度。色盲安全：通过 Protanopia/Deuteranopathy 模拟验证，必要时用亮度差异补偿。

稀有度标记在技能解锁时的 UI 弹窗和图标边框上 — 普通=白框、稀有=紫框、史诗=金框。特效本身永远是施放者的职业色。

服务支柱：**秒学秒玩** + **高手菜鸟都开心**
- 秒学秒玩：颜色 = 身份，不需要学习
- 高手菜鸟都开心：菜鸟通过颜色知道「红方在攻击」，高手通过颜色+形状+动画读取完整信息

## 2. Mood & Atmosphere

### 情绪总纲

**「从客厅沙发到擂台风暴，再回到沙发的微笑」** — 每一次对局是朋友聚会中的一局游戏：开场轻松随意，过程中逐渐升温到沸腾高潮，结束时无论输赢都带着笑意回到社交氛围。

### 2.1 战斗大厅 / 角色选择

**情绪目标**：轻松、社交、期待 — 朋友们坐在沙发上一起挑角色

- **灯光性格**：暖色调（色温约 4200K），低对比度。背景 #222240（#1A1A2E 的暖色变体），全局柔和均匀，无硬阴影。职业色以低饱和度出现在角色预览上，营造「还没上场的选手在休息区」的感觉。
- **氛围形容词**：温暖、松弛、社交、好奇、跃跃欲试
- **能量等级**：2/10
- **情绪载体**：**呼吸灯环境光** — 背景有极缓慢的明暗周期（约4秒），像房间在轻轻呼吸。角色选择确认时，选中角色的职业色以脉冲方式融入环境光。

### 2.2 比赛开始

**情绪目标**：期待感、紧张感的缓慢起步 — 拳击手碰拳前的对视

- **灯光性格**：从大厅暖色缓慢过渡到偏冷中性（色温约 5500K），对比度提升。背景回到标准 #1A1A2E。倒计时 "3-2-1" 每一下数字消失时，环境光微微闪烁一次（亮度短暂提升10%）。
- **氛围形容词**：凝聚、屏息、仪式感、对峙、微颤
- **能量等级**：3/10 → 4/10（"FIGHT!" 跳到 5）
- **情绪载体**：**开幕闪光** — "FIGHT!" 出现的瞬间，两侧职业色从边缘向中心快速扫过一次然后熄灭，留下纯净战场。

### 2.3 开局试探（0-1个技能）

**情绪目标**：谨慎、试探、学习 — 两只猫第一次见面

- **灯光性格**：冷中性（色温约 5800K），中等对比度。背景 #1A1A2E 保持纯净。角色身上仅有最基础的职业色轮廓光（亮度约30%）。全场最「干净」的视觉状态。
- **氛围形容词**：清澈、冷静、谨慎、干净、肃静
- **能量等级**：3/10
- **情绪载体**：**静默的能量轮廓** — 角色边缘有极微弱的职业色光晕，频率极慢（约3秒周期），像心跳很慢。没有粒子、没有环绕元素。安静本身就是信息。

### 2.4 成长加速（2-3个技能）

**情绪目标**：兴奋、加速、发现 — 过山车刚开始下坡

- **灯光性格**：缓慢偏暖（色温约 5000K），对比度明显提升。背景开始出现微弱的职业色渲染（获得技能时，该侧边缘染上淡淡职业色），渲染亮度不超过背景的15%。角色轮廓光亮度提升到60%，脉动频率加快（约1.5秒周期）。
- **氛围形容词**：升温、活跃、多变、节奏感、觉醒
- **能量等级**：5/10 → 6/10
- **情绪载体**：**职业形状碎片环绕** — 角色周围出现与职业形状一致的小型几何碎片缓慢环绕（战士=小矩形、法师=小三角、盗贼=小菱形）。碎片数量 = 已解锁技能数。每次新技能解锁时，碎片从角色中心爆出并入轨 — 这是「节奏在变」的关键触点。

### 2.5 混乱高潮（4+个技能）

**情绪目标**：狂热、失控的快感、巅峰体验 — 演唱会最炸的那首歌

- **灯光性格**：暖偏热（色温约 3800K），高对比度。背景被双方职业色同时渲染，形成双色对撞氛围，背景渲染亮度可达25%。角色轮廓光亮度90%，脉动频率极快（约0.8秒周期）。技能命中瞬间出现白色高光闪烁（1-2帧）。
- **氛围形容词**：沸腾、密集、炸裂、绚丽、酣畅
- **能量等级**：8/10 → 9/10
- **情绪载体**：**形状碎裂与屏幕震动** — 环绕碎片轨道变得不规则。技能命中时，被命中方的碎片被「打碎」— 分裂为更小几何微粒向外散射（约0.3秒），然后重新凝聚。叠加轻微屏幕震动（振幅2-3像素）。全游戏视觉密度最高的时刻，但每个元素仍是可识别的几何形状。

### 2.6 胜利

**情绪目标**：庆祝、爽快、派对高潮 — 赢了一局后跟朋友击掌

- **灯光性格**：暖色爆发（色温约 3200K），高亮度。胜者职业色成为全场主色调，从中心向四周扩散。整体亮度提升约20% — 全场最亮的时刻。庆祝通过职业色几何形状动画表达（战士=矩形碎片向上弹射、法师=三角形旋转扩散）。
- **氛围形容词**：辉煌、释放、满足、骄傲、欢乐
- **能量等级**：10/10 瞬间释放 → 5/10（结果画面回落）
- **情绪载体**：**职业色几何庆祝波** — "VICTORY!" 瞬间，从胜者中心爆发出一圈大尺寸职业色几何形状向外快速扩散。背景出现该职业色的放射状几何光线条纹，持续约1.5秒后淡出。之后环境回到温暖柔和光照，暗示「回到客厅，准备下一局」。

### 2.7 失败

**情绪目标**：轻松鼓励、不甘心、再来一局 — "我不服，再来！"

- **灯光性格**：中性偏暖（色温约 4500K），中低对比度。败者职业色以低亮度（约15%）柔和渲染背景，不是「被压制」的感觉 — 更像「这个颜色还在，等你回来」。不使用暗角、灰色滤镜、不降低饱和度。
- **氛围形容词**：温暖、不服、鼓励、从容、期待
- **能量等级**：3/10 — 平静但带有微弱上扬感
- **情绪载体**：**职业色的「还没完」脉动** — 败者职业色轮廓光以约2秒周期缓慢脉动，每次脉动比上次微弱地亮一点点（+2%/周期），暗示「能量在重新积蓄」。不使用「碎裂」「暗淡」视觉语言 — 失败不是破碎，是暂停。

## 3. Shape Language

### 3.1 角色剪影哲学

每个角色必须在 48x48 像素缩略图尺寸下一眼识别职业身份。三层编码：

**第一层（形状原型）**：核心外轮廓吻合职业契约 — 战士内切矩形、法师内切三角形、盗贼内切菱形。

**第二层（体型比例）**：
- 战士：宽高比约 1:0.85（宽厚），重心低，底盘稳固
- 法师：宽高比约 1:1.4（高瘦），重心偏高，轮廓向上收束
- 盗贼：宽高比约 1:1.1（紧凑菱形），重心灵活

**第三层（质感暗示）**：战士轮廓硬朗棱角分明（转角接近直角），法师有轻微尖刺感，盗贼锋利且流畅。

**默认站姿是身份声明**：
- 战士：双脚与肩同宽，微蹲，双拳置腰侧 — 梯形/墙壁
- 法师：单脚微前，单手抬起蓄能 — 向上收束的三角/尖塔
- 盗贼：前倾微蹲，双手半伸 — 向前倾斜的菱形/箭头

**技能解锁对剪影的影响**：已解锁技能在角色轮廓上叠加形状附属物：
1. 附属物形状必须属于职业形状家族（战士仍是矩形变体）
2. 附属物大小不超过角色本体轮廓的 30%
3. 附属物位置有固定锚点（护盾=前臂、投射=掌心、增益=头部/背部）
4. 最多同时显示 3 个附属物

| 技能类型 | 战士附属物 | 法师附属物 | 盗贼附属物 | 位置 |
|---|---|---|---|---|
| 护盾/防御 | 矩形板 | 三角屏障 | 菱形镜面 | 前臂外侧 |
| 投射/远程 | 矩形弹头 | 三角箭头 | 菱形针 | 掌心 |
| 增益/自身 | 矩形光环 | 三角冠 | 菱形眼罩 | 头部/背部 |
| 位移/突进 | 矩形尾迹 | 三角翼 | 菱形残影 | 腿部/脚底 |

### 3.2 环境几何

**核心规则：环境用曲线和有机形状，角色用直线和锐角。** 角色的几何锐利度天然与环境形成对比。

**平台**：主平台为大型圆角矩形（圆角半径约 15-20%），浮动平台边缘更柔和（25-30%）。所有平台宽度大于高度，形成「支撑感」。

**边界**：不使用硬边框，使用渐变雾化。击飞区域外完全透明（纯黑+微弱星空粒子）。

**装饰层**：
- 远景：大尺寸低对比度有机形状，完全不使用锐角
- 中景：中等尺寸，可有轻微棱角但必须是钝角（>120度）
- 近景：极少使用，高透明度（<40%），不与角色运动路径重叠

**场地与角色的对比系统**：色温对比（场地冷/中性 vs 角色暖/饱和）、锐度对比（场地圆角 vs 角色直角）、纹理密度对比（场地有低调纹理 vs 角色纯色填充）、动画对比（场地缓慢环境动画 vs 角色快速果断）。

### 3.3 UI 形状语法

UI 使用独立的硬边几何语言，不复制世界或角色风格。三层视觉系统：

```
角色层：锐角几何 + 高饱和职业色 → 最突出
环境层：圆角有机 + 低饱和冷色   → 最安静
UI层  ：硬边几何 + 中性色/职业色 → 信息清晰但不抢焦点
```

**血条**：圆角极小矩形（<3px），高度12px，每25%有微小缺口，最后25%危险区暗红脉冲。1px 职业色描边。固定屏幕上方，不跟随角色。

**专注值条**：紧贴血条下方的细矩形（6px高），用职业形状微缩排列填充（战士=微型矩形块、法师=微型三角、盗贼=微型菱形）。满值时闪烁职业色。

**技能图标**：正方形底板（暗灰 #2A2A3E）+ 职业色边框。图标核心包含施放者职业形状。稀有度通过边框区分（普通=1px白线、稀有=2px紫线+发光、史诗=3px金线+明显发光）。

**伤害数值**：硬边无衬线字体。普通16px、重击24px、暴击32px+职业色描边。向上偏移15度飞出。

**屏幕布局**：顶部中央显示比分和回合信息，战斗区域居中，底部左右角分别显示 P1/P2 信息区（伤害百分比+专注值条+技能槽位组）。信息区不遮挡中央战斗区域（屏幕中央 70% 无 UI 元素）。

### 3.4 视觉层级

**Level 1（最突出）— 角色本体**：对比度最高、锐利度最高（无圆角直角）、运动幅度最大。任何特效/环境/UI不允许超过角色本体的亮度、饱和度、锐利度。

**Level 2（可读但退后）— 活跃技能特效**：职业色半透明（60-70%），形状边缘允许轻微模糊，单帧总特效面积不超过屏幕15%。

**Level 3（最低存在感）— 环境+非活跃UI**：低饱和、低亮度、高透明。混乱高潮时可进一步降至60%不透明度。

**混乱高潮可读性保障**：
- 同时特效元素硬上限 = 12个（每方6个），超出时最早特效加速衰减
- 单个特效尺寸上限 = 屏幕短边的20%
- 不同职业特效重叠时交汇区域产生2帧白色闪光作分隔符
- 角色本体永远不被特效遮挡（特效渲染层在角色之下）

### 3.5 不可违约规则

| # | 规则 | 服务支柱 |
|---|---|---|
| 1 | 战士=矩形、法师=三角、盗贼=菱形。不交叉 | 秒学秒玩 |
| 2 | 角色锐利度 > 特效锐利度 > 环境锐利度 | 快速战斗 |
| 3 | 同时可识别形状总数不超过14个 | 快速战斗 |
| 4 | 特效颜色归属跟随施放者职业色 | 秒学秒玩 |
| 5 | 技能附属物≤本体轮廓30%，最多显示3个 | 每局都是新故事 |
| 6 | 环境圆角≥15%，角色圆角≤5% | 秒学秒玩 |
| 7 | UI独立硬边语言，不与环境或角色融合 | 高手菜鸟都开心 |

## 4. Color System

### 4.1 基础色板

| 色彩名称 | Hex | 角色 |
|---|---|---|
| 战士红 | #E84545 | 战士身份色 — 攻击、威胁、正面冲撞 |
| 法师蓝 | #5EADF2 | 法师身份色 — 神秘、远程、精确、元素控制 |
| 盗贼绿 | #2ECC71 | 盗贼身份色 — 狡猾、敏捷、毒性、隐蔽偷袭 |
| 深渊底 | #1A1A2E | 世界底色 — 竞技场的「空虚」，所有能量在此被照亮 |
| 纯白 | #FFFFFF | 命中高光、系统文字、中性信息 — 纯净冲击力瞬间 |
| 赤金 | #F0C040 | 稀有度标记（史诗级）、胜利强调、成就高光 |
| 暗紫 | #9B59B6 | 稀有度标记（稀有级）、特殊负面状态（沉默/封印） |

新增颜色前必须回答：它传达的信息能否被已有颜色替代？

### 4.2 语义色彩

**职业色 = 身份 + 所有权**：
- 红色 = 战士的一切（特效、伤害数字、弹道、Buff光环）。即使使用冰冻技能，特效仍为红色。
- 蓝色 = 法师的一切（攻击区域指示器、弹道轨迹、持续伤害标记）。
- 绿色 = 盗贼的一切（陷阱标记、毒雾区域、闪避残影）。

**纯白 = 系统级冲击**：技能命中1-2帧白色闪光（不属于任何职业）、伤害数字填充色、系统通知文字（"FIGHT!"、"VICTORY!"、技能解锁）、专注值条填充。

**赤金 = 成就与稀有**：仅UI层。史诗技能图标边框、解锁弹窗高光描边、胜利画面名字描边。绝不出现在战斗特效中。

**暗紫 = 特殊状态与稀有度**：稀有技能UI图标边框、负面状态指示环（不与任何职业色冲突）。绝不出现在正面/增益效果中。

**深渊底 = 舞台**：仅做背景，不用于任何UI或文字。

**被排除的用法**：黄色/橙色特效（与赤金色相近易误读）、粉色治疗（饱和度难控）、灰色负面状态（=暗淡=不重要，与紧迫感矛盾）。

### 4.3 色温随游戏状态流转

| 游戏状态 | 色温 | 背景 | 职业色表现 | 对比度 |
|---|---|---|---|---|
| 角色选择 | 暖~4200K | #222240（暖色变体） | 低饱和30% | 低 |
| 比赛开始 | 冷~5500K | #1A1A2E（标准） | 中等40% | 中 |
| 开局试探 | 冷中性~5800K | #1A1A2E（纯净） | 轮廓光30% | 中 |
| 成长加速 | 偏暖~5000K | +15%职业色渲染 | 轮廓光60% | 中高 |
| 混乱高潮 | 暖热~3800K | +25%双色对撞渲染 | 轮廓光90% | 高 |
| 胜利 | 暖爆发~3200K | 胜者职业色全覆盖 | 亮度100% | 极高 |
| 失败 | 中偏暖~4500K | 败者色15%柔和渲染 | 缓慢脉动(+2%/周期) | 低中 |

色温从冷到暖映射能量从低到高 — 直觉级情绪引导。

### 4.4 UI 色板

**与战斗世界共享**：深渊底（面板背景）、三种职业色（血条/头像框/名牌）。

**UI 专用颜色**（不出现在战斗特效中）：

### 4.5 色盲安全

**危险色对**：
- 红色盲/绿色盲：战士红 vs 盗贼绿 — **高风险**
- 蓝黄色盲：法师蓝 vs 深渊底 — **中低风险**
- 蓝黄色盲：史诗金 vs 稀有紫 — **中等风险**

**已内置安全机制**：形状语言提供独立身份通道（矩形vs三角vs菱形）。

**额外备用信号**：

| 场景 | 备用信号 |
|---|---|
| 区分玩家 | P1/P2 文字标识 + 不同几何边框（P1方形、P2圆形） |
| 识别技能归属 | 特效生成时0.15秒「起源连线」从角色到特效起点 |
| 专注值进度 | 每25%增加菱形图标标记 |
| 稀有度区分 | 边框图案差异（白纯线/紫虚线/金宽线+闪光） |
| 负面状态 | 紫色环 + 脉动动画 + 微型状态图标 |
| 命中感知 | 白色闪光 + 轻微屏幕震动（1-2像素） |

**亮度安全**：战士红 3.8:1（AA大文本）、法师蓝 5.2:1（AA）、盗贼绿 5.6:1（AA）。如需进一步拉开，战士红可调至 #D03030。

**色盲测试要求**：每次新增视觉元素需通过红色盲/绿色盲/蓝黄色盲模拟验证。不能区分则增加形状/图标/动画备用信号。

## 6. Environment Design Language

### 6.1 建筑风格 — 竞技场是什么地方？

**核心概念：「能量斗技场」— 抽象化的仪式空间，不是真实地点。**

职业对决的场地不是「某条街」「某座城」——它们是纯粹的战斗仪式空间。建筑风格遵循**几何抽象主义**：结构元素是对真实建筑的几何提炼，而非对现实的描摹。

**建筑语汇规则**：

- **柱体** = 圆角矩形（不是圆柱），传达「支撑/稳定」
- **拱门** = 半椭圆弧线（不是哥特尖拱），传达「通道/开放」
- **台阶** = 递减宽度圆角矩形堆叠，传达「层次/上升」
- **墙壁** = 带圆角的大面积色块，无砖纹、无裂缝、无写实质感

所有建筑元素必须通过以下三重检验：
1. **简化检验**：去掉任何一个细节后，这个元素是否仍然能被识别？（如果能，说明细节过多）
2. **圆角检验**：所有转角半径是否 ≥15%？（建筑锐度绝不允许接近角色锐度）
3. **退后检验**：纯黑白渲染时，该元素是否明显暗于任何角色剪影？

**禁止出现的建筑语言**：写实材质（砖、石、木纹）、透视消失点建筑、带有功能细节的写实结构（窗户格栅、门把手、管道）。场地是**抽象舞台布景**，不是微缩模型。

**为什么选择抽象而非写实？**
- 与角色几何风格统一（写实环境 + 几何角色 = 视觉断裂）
- 简化素材制作管线（圆角色块 vs 纹理贴图素材包）
- 保证环境永远退后（Level 3 视觉优先级）——抽象风格天然不具备吸引注意力的细节密度

### 6.2 纹理哲学 — 手绘风格化

**决策：手绘矢量风格（Vector-Handpainted Hybrid），非 PBR，非纯像素。**

**材质表达公式**：

```
材质 = 底色填充（单色/微渐变）+ 边缘高光（1px 亮色描边，内偏移）+ 表面暗示（极少量手绘线条）
```

三层表达的权重分配：

| 层级 | 占视觉比重 | 用途 | 示例 |
|---|---|---|---|
| 底色填充 | 80% | 定义材质身份 | 平台 = #2A2A4E（深蓝灰），石质 = 偏冷灰 |
| 边缘高光 | 15% | 暗示体积和光照方向 | 统一从左上方打光，右下边缘更暗 |
| 表面暗示 | 5% | 材质质感 | 极少量手绘短线/点，暗示石纹、木纹、金属 |

**禁止的纹理手法**：
- 噪点纹理叠加（增加视觉噪音，违反「能读懂才允许炫」铁律）
- 法线贴图/凹凸映射（2D 项目不适用，且引入不需要的写实感）
- 照片来源纹理（与几何风格冲突）
- 超过3个色阶的渐变（过度渲染 = 吸引不该有的注意力）

**为什么选手绘矢量而非其他方案？**
- **PBR**：与2D几何角色完全不兼容，制作成本高，且写实光照会抢夺角色注意力
- **纯像素**：限制分辨率灵活性，放大后锯齿明显，且与本项目的矢量几何线条冲突
- **手绘矢量**：与形状语言天然统一（矢量 = 精确几何），缩放无损，制作高效（色块 + 描边），且能传达足够的材质信息而不喧宾夺主

**平台材质规范**：

| 元素 | 底色 | 边缘高光 | 表面暗示 | 圆角半径 |
|---|---|---|---|---|
| 主平台 | #2A2A4E | #3D3D6B（上缘） | 无 | 15-20% |
| 浮动平台 | #252548 | #383868（上缘） | 无 | 25-30% |
| 装饰石块（远景） | #1E1E3A | 无 | 极淡短线 | 35-50% |
| 装饰石块（中景） | #242444 | #303058（局部） | 1-2条手绘线 | 20-35% |
| 边界雾化 | #1A1A2E → 透明 | 无 | 无 | N/A |

### 6.3 道具密度规则 — 稀疏为原则

**密度哲学：「每一件装饰物都必须通过'遮住它时画面是否会变空'的测试。」**

环境装饰不是填充物——它是空间定义的工具。道具稀疏是原则，密集是例外。

**三区密度规范**：

| 区域 | 道具数量 | 功能 | 示例 |
|---|---|---|---|
| **战斗区**（角色活动范围） | 0 | 零道具。平台本身就是唯一结构元素 | 主平台、浮动平台 |
| **氛围区**（战斗区外但视觉内） | 2-4件/屏 | 定义场地主题，暗示空间深度 | 远景建筑剪影、远景天体 |
| **过渡区**（屏幕边缘） | 1-2件/边 | 柔化画面边缘，暗示世界延伸 | 渐变雾化、极淡粒子 |

**道具大小层级**：

```
远景道具：屏幕尺寸 20-40% → 对比度 ≤15%（与背景差值） → 零锐角
中景道具：屏幕尺寸 8-15% → 对比度 ≤25% → 允许钝角（>120度）
近景道具：屏幕尺寸 3-8% → 对比度 ≤10%（高透明补偿） → 禁止在角色路径上
```

**密度驱动因素**：道具密度唯一的作用是**定义场地主题身份**。两个场地之间的视觉差异主要通过远景装饰的主题和轮廓来区分——而非通过密度竞赛。

**MVP 道具清单**（每场地）：
- 远景装饰 2-3 件（大型有机形状剪影）
- 中景装饰 1-2 件（中等结构暗示）
- 近景装饰 0-1 件（极淡，仅在需要纵深时使用）
- 边界雾化（必须，非可选）
- 背景粒子（星空/浮尘，密度 ≤ 15颗粒/屏，移动速度 ≤ 2px/帧）

### 6.4 环境叙事 — 视觉细节如何讲述故事

**叙事哲学：「场地不讲述剧情——它讲述规则。」**

职业对决是派对格斗，不是冒险游戏。场地的「故事」不是「这里曾经发生过什么」，而是**「这是什么样的战斗空间」**。

**环境传达的三层信息**：

**第一层：空间功能（即时读取）**
- 平台布局直接告诉玩家「你可以怎么移动」——无文字，纯视觉
- 大平台 = 安全区，小浮动平台 = 风险/机会区
- 平台间距暗示击飞角度的风险等级

**第二层：主题身份（3秒内读取）**
- 远景装饰的轮廓和主题色暗示定义「这是什么地方」
- 不需要文字标签——形状语言就是叙事
- 每个场地的主题身份通过 2-3 个标志性远景元素锚定

**第三层：情绪基调（无意识读取）**
- 色温、明暗、装饰密度共同营造场地氛围
- 冷色调场地 → 谨慎、精确、冷静
- 暖色调场地 → 激进、混乱、热情
- 但注意：场地基调仅是「默认状态」，战斗中的色温流转（Section 2）覆盖场地基调

**叙事禁止项**：
- 文字标牌/招牌/涂鸦（干扰战斗可读性）
- 可交互叙事物件（开宝箱、读石碑——不属于本游戏类型）
- 复杂的背景事件（移动的人群、飘过的飞船——制造视觉噪音）
- 季节/天气系统（增加不必要的视觉复杂度）

**唯一的「叙事动态」：色温随战斗状态变化。** 场地从冷色安静逐步升温到暖色沸腾——这就是场地在战斗中讲述的全部故事：「能量在积累，高潮在到来。」

### 6.5 示例场地设计 — 主题差异中的视觉统一

以下三个示例场地展示如何在维持视觉统一性的前提下创造鲜明的主题差异。它们共享同一套形状语言、纹理哲学和密度规则，但通过远景主题、色温偏移和装饰轮廓来区分身份。

#### 场地A：「星坛」（Stellar Altar）

**主题身份**：悬浮在虚空中的古老仪式平台，星空为幕。

**情绪基调**：肃穆、神秘、宇宙尺度的庄严。适合作为默认场地——它的中性气质不偏向任何职业。

**空间布局**：
```
              ┌────────┐
              │ 浮动台3 │
    ┌───────┐ └────────┘ ┌───────┐
    │浮动台1│             │浮动台2│
    └───────┘             └───────┘
    ╔══════════════════════════════╗
    ║        主 平 台              ║
    ╚══════════════════════════════╝
```

**视觉规范**：

| 元素 | 规格 | 说明 |
|---|---|---|
| 主平台 | 宽 60%，高 6%，圆角 18% | 标准大型圆角矩形，深蓝灰底色 |
| 浮动台1/2 | 宽 18%，高 4%，圆角 25% | 左右对称，柔和圆角 |
| 浮动台3 | 宽 14%，高 3.5%，圆角 28% | 中央高位小平台 |
| 远景装饰 | 2件：巨大圆环 + 六角形结构 | 轮廓占屏幕25-35%，对比度≤12% |
| 背景粒子 | 星空型，12颗，缓慢漂移 | 亮度≤20%，无闪烁 |
| 边界雾化 | 四边渐变透明 | 标准深渊底→透明 |

**远景叙事元素**：
1. **巨大圆环**（屏幕左上）：一个直径约屏幕30%的空心圆环，极低对比度（与背景差值≤10%），缓慢旋转（1度/帧）。暗示「古老的仪式环」——不说明是什么，让玩家自己想象。
2. **六角形结构**（屏幕右下）：由六个等边三角形组成的蜂巢图案局部，极淡描边，无填充。暗示「某种秩序/系统」——与战斗的混乱形成对照。

**色温偏移**：基准色温 5500K（中性偏冷），在战斗状态流转中作为「零点」——其他场地在此基础上偏移。

**与其他场地的区分锚点**：巨大圆环 + 星空背景 = 「星坛」的唯一视觉签名。

#### 场地B：「熔窟」（Molten Cavity）

**主题身份**：地底熔岩洞穴，温暖的压迫感。

**情绪基调**：压抑、灼热、危险中带美感。暖色偏重的场地——天然适合表达「激进/高风险」的战斗氛围。

**空间布局**：
```
    ┌───────┐                 ┌───────┐
    │浮动台1│                 │浮动台2│
    └───────┘                 └───────┘
              ┌──────────────┐
              │   浮动台3    │
              └──────────────┘
    ╔══════════════════════════════╗
    ║        主 平 台              ║
    ╚══════════════════════════════╝
```

**视觉规范**：

| 元素 | 规格 | 说明 |
|---|---|---|
| 主平台 | 宽 58%，高 6%，圆角 15% | 略窄于星坛，底部边缘有微弱暖色光晕 |
| 浮动台1/2 | 宽 16%，高 4%，圆角 22% | 高位侧平台，布局偏进攻型 |
| 浮动台3 | 宽 22%，高 4%，圆角 20% | 中央低位大平台，提供额外立足空间 |
| 远景装饰 | 3件：钟乳石群 + 熔岩池 + 洞顶拱形 | 有机形状为主，暗示地质结构 |
| 背景粒子 | 火星型，15颗，上升漂浮 | 暖橙色，亮度≤15%，向上缓慢漂浮 |
| 边界雾化 | 底边暖色渐变，其余三边标准 | 底部暗示熔岩光源 |

**远景叙事元素**：
1. **钟乳石群**（屏幕上方）：3-5个倒置的圆角三角形/水滴形，从画面上方垂下。底色 #2E2020（暖深棕），无锐角尖端——所有尖端以圆弧收束。暗示「洞穴顶部」。
2. **熔岩池**（屏幕下方）：画面底部一条水平色带，#3A1A1A 底色 + 微弱脉动的 #4A2525 高光（约4秒周期，与大厅呼吸灯节奏一致）。不直接可见熔岩——只有暖色光暗示它的存在。
3. **洞顶拱形**（远景最深处）：一个巨大的半椭圆弧线，极低对比度（≤8%），定义「被包裹的空间感」。

**色温偏移**：基准色温 4500K（偏暖），比星坛暖一个档位。开局试探阶段仍保持中性（5800K），但该场地的「暖」起点比星坛提前进入成长加速阶段。

**与星坛的视觉差异**：

| 维度 | 星坛 | 熔窟 |
|---|---|---|
| 远景主题 | 几何天体（圆环/六角） | 有机地质（钟乳石/拱形） |
| 背景粒子方向 | 随机漂移 | 向上漂浮（热气上升） |
| 底部处理 | 标准雾化 | 暖色光晕（暗示熔岩） |
| 空间感 | 开放/无限 | 封闭/包裹 |
| 基准色温 | 5500K（冷中性） | 4500K（偏暖） |
| 装饰轮廓 | 精确几何（圆/六角） | 有机不规则（水滴/拱形） |

**与星坛的视觉统一**（不变项）：深渊底主色、平台圆角矩形形状语言、手绘矢量纹理、Level 3 视觉优先级、密度规则。

#### 场地C：「晶场」（Crystal Arena）

**主题身份**：悬浮在几何晶体矩阵中的开放战场，秩序与能量的交汇。

**情绪基调**：精确、紧张、能量感。冷色调场地——天然适合表达「技巧/精确」的战斗氛围。通过「晶体」元素呼应游戏的「能量」视觉锚点。

**空间布局**：
```
              ┌────────┐
              │ 浮动台2 │
    ┌────┐    └────────┘    ┌────┐
    │台1 │                  │台3 │
    └────┘                  └────┘
    ╔══════════════════════════════╗
    ║        主 平 台              ║
    ╚══════════════════════════════╝
```

**视觉规范**：

| 元素 | 规格 | 说明 |
|---|---|---|
| 主平台 | 宽 62%，高 6%，圆角 16% | 最宽主平台，偏保守布局 |
| 浮动台1 | 宽 12%，高 3.5%，圆角 30% | 极小左侧平台，高技巧要求 |
| 浮动台2 | 宽 16%，高 4%，圆角 25% | 中央高位平台 |
| 浮动台3 | 宽 12%，高 3.5%，圆角 30% | 极小右侧平台，与台1对称 |
| 远景装饰 | 2件：巨型棱柱 + 浮游晶体簇 | 几何/晶体主题，允许锐角（仅远景） |
| 背景粒子 | 棱形微粒，10颗，缓慢漂浮 | 极小菱形，冷蓝白色，亮度≤10% |
| 边界雾化 | 四边标准渐变透明 | 冷色调雾化（偏蓝灰） |

**远景叙事元素**：
1. **巨型棱柱**（屏幕右上）：一个大型六边形棱柱的侧视剪影，底色 #1E1E3E，以极淡的 #2A2A50 描边。约屏幕高度的40%。缓慢上下浮动（幅度约2%，周期约8秒）。暗示「某种能量结构的残骸」——呼应游戏的「能量」视觉锚点。
2. **浮游晶体簇**（屏幕左下）：5-7个大小不一的菱形/六边形散布在一片区域，整体构成一个松散簇群。极低对比度（≤10%）。个别晶体有极缓慢的自旋。暗示「散落的能量碎片」。

**关键设计决策——远景允许锐角的例外说明**：
晶场的远景晶体元素包含锐角（菱形的尖端），这看似违反「环境用曲线和有机形状」的核心规则。但以下条件使其成立：
- 锐角仅出现在**远景装饰**上（与战斗区零重叠）
- 远景对比度极低（≤10%），锐角在视觉上几乎不被感知
- 晶体的「菱形」与盗贼的职业形状（菱形）存在呼应，但远景的低对比度使其不可能与角色混淆
- 此例外仅限于晶场主题——不作为其他场地的先例

**色温偏移**：基准色温 6000K（偏冷），三个示例场地中最冷的。开局试探阶段达到全场最冷的视觉状态（约6200K），强化「精确/冷静」的情绪基调。

**与星坛、熔窟的完整对比**：

| 维度 | 星坛 | 熔窟 | 晶场 |
|---|---|---|---|
| 远景主题 | 几何天体 | 有机地质 | 能量晶体 |
| 空间感 | 开放/无限 | 封闭/包裹 | 开放/结构化 |
| 基准色温 | 5500K | 4500K | 6000K |
| 背景粒子 | 星光漂移 | 火星上升 | 棱形悬浮 |
| 底部处理 | 标准雾化 | 暖色光晕 | 冷色雾化 |
| 装饰轮廓 | 精确几何 | 有机不规则 | 锐利几何（低对比度） |
| 情绪关键词 | 肃穆/神秘 | 压抑/灼热 | 精确/紧张 |
| 平台布局 | 三层对称 | 两层进攻型 | 三层不对称 |
| 道具数量 | 2远景 | 3远景 | 2远景 |

**三者共享的不变量**（视觉统一性锚点）：
- 深渊底 (#1A1A2E) 作为主背景色（仅微调色温偏移，色相不变）
- 所有平台 = 圆角矩形（圆角 ≥15%）
- 手绘矢量纹理（底色80% + 边缘高光15% + 表面暗示5%）
- 道具密度 ≤ 4件/屏
- Level 3 视觉优先级（永远退后于角色和特效）
- 边界雾化（四边渐变，不允许硬边框）
- 战斗区零道具（平台是唯一结构元素）

每个新场地必须通过以下全部检验才能通过艺术审核：

| # | 检验项 | 通过标准 |
|---|---|---|

## 7. UI/HUD Visual Direction

### 7.1 排版方向（Typography）

**字体人格**：硬边、冷静、工具感 — 不装饰，只传达。UI字体是战场上的「裁判」，不是「选手」。它不需要有性格，但必须绝对公正清晰。

**字体选择标准**：

| 用途 | 字体特征 | 尺寸层级 | 字重 | 示例场景 |
|---|---|---|---|---|
| 系统大字 | 几何无衬线、笔画均匀、无装饰线 | 48-64px | Medium (500) | "FIGHT!"、"VICTORY!"、倒计时数字 |
| UI标题 | 同族字体 | 20-24px | Semi-Bold (600) | 面板标题、技能名称、职业名 |
| UI正文 | 同族字体 | 14-16px | Regular (400) | 技能描述、状态提示、选项文本 |
| 伤害数字 | 等宽无衬线、数字宽度一致 | 16/24/32px | Bold (700) | 浮动伤害/治疗数值 |
| 微型标注 | 同族字体，强制大写 | 10-12px | Medium (500) | 按键提示、缩写状态标签、稀有度标签 |

**推荐字体族方向**（需技术-美术确认引擎内渲染效果）：
- **首选参考**：Exo 2 / Rajdhani / Orbitron 类几何无衬线字体 — 圆角极小，笔画有微弱机械感，天然匹配硬边几何语言
- **中文回退**：思源黑体（Noto Sans SC）— 无衬线，笔画干净，与几何无衬线英文混排不违和
- **禁止**：衬线字体（破坏硬边感）、手写/毛笔字体（与几何风格矛盾）、圆体（与角色锐利感冲突）

**排版硬规则**：

1. **最小字号 10px** — 低于此尺寸的信息不被显示，改用图标
2. **字间距 = 字号的 3-5%** — 几何字体需要呼吸空间，不能挤在一起
3. **行高 = 字号的 140-160%** — 保证多行文本可读性
4. **伤害数字强制等宽** — 同一伤害序列中不同数字宽度必须一致，防止视觉跳动
5. **所有数字使用 tabular-nums 特性** — 计时器、血量数值不因数字变化而宽度抖动
6. **中英文混排**：英文/数字使用几何无衬线主字体，中文自动回退到思源黑体，行高中取较大值

**文字颜色编码**：

| 文字类型 | 颜色 | 来源 |
|---|---|---|
| 系统大字（"FIGHT!"、"VICTORY!"） | #FFFFFF 纯白 | 4.4 UI文字强调 |
| 面板标题 | #FFFFFF 纯白 | 4.4 UI文字强调 |
| 正文/描述 | #E8E8F0 UI文字主色 | 4.4 UI文字主色 |
| 伤害数字填充 | #FFFFFF | 纯白系统级 |
| 伤害数字描边（暴击） | 职业色 | 4.1 职业色 |
| 禁用/不可交互 | #3A3A5C UI中性灰（降低不透明度至50%） | 4.4 UI中性灰 |
| 倒计时紧急态（<5秒） | #E84545 战士红 | 借用危险信号色 |

### 7.2 图标风格（Iconography）

**核心定位：平面几何符号（Flat Geometric Glyph）** — 不是写实图标、不是像素图标、不是线条图标。每个图标是一个在深色底板上用简单几何形状组合传达含义的符号。

**风格定义**：

```
图标 = 深色方底板 + 职业色几何形状组合 + 稀有度边框

层次：
┌─────────────────┐
│  稀有度边框（1-3px）│  ← 白/紫/金
│ ┌─────────────┐ │
│ │  暗灰底板     │ │  ← #2A2A3E
│ │ ┌─────────┐ │ │
│ │ │ 几何符号  │ │ │  ← 职业色填充
│ │ │（形状组合）│ │ │
│ │ └─────────┘ │ │
│ └─────────────┘ │
└─────────────────┘
```

**图标规格矩阵**：

| 参数 | 技能图标 | 状态图标 | 菜单图标 | 微型图标 |
|---|---|---|---|---|
| 底板尺寸 | 40x40px | 24x24px | 32x32px | 16x16px |
| 底板颜色 | #2A2A3E | 透明+职业色描边 | #2A2A3E | 透明 |
| 符号区域 | 24x24px（底板居中） | 16x16px | 20x20px | 12x12px |
| 圆角 | 4px（10%） | 0px（硬边） | 4px | 0px |
| 描边宽度 | 1px 内缩 | 1px | 1px 内缩 | 无 |
| 用途 | 技能栏、解锁弹窗 | 血条旁状态 | 菜单按钮 | 专注值条内 |

**几何符号设计原则**：

1. **形状即含义** — 攻击类图标核心使用职业形状的「尖锐变体」（战士=矩形斜置、法师=三角形朝前、盗贼=菱形旋转45度）；防御类使用「宽平变体」（矩形横置、三角形底边朝前、菱形横置为菱形盾）；增益类使用「环绕变体」（形状组合成环形/放射状）

2. **2-4个几何元素** — 每个图标由2到4个基础几何形状组合而成。单个形状过于单调，超过4个在16px尺寸下无法辨认

3. **负空间清晰** — 图标内任何形状之间的间距不低于2px（以40x40底板为基准），形状不能粘连

4. **职业色填充 + 纯白高光点** — 图标符号主体用职业色填充，关键焦点（如剑尖、箭头指向、能量核心）允许一个1-2px的纯白高光点引导视线

5. **锁定/不可用态** — 底板不变，符号颜色从职业色降为 #3A3A5C（UI中性灰），叠加对角线斜杠（1px，#3A3A5C）

**稀有度边框系统**：

| 稀有度 | 边框规格 | 额外效果 |
|---|---|---|
| 普通 | 1px #FFFFFF 实线 | 无 |
| 稀有 | 2px #9B59B6 实线 + 外发光（模糊半径3px，不透明度30%） | 静止状态微弱脉动（亮度周期5%波动） |
| 史诗 | 3px #F0C040 实线 + 外发光（模糊半径5px，不透明度50%） | 持续旋转光晕（2px宽金色细线沿边框缓慢旋转，约4秒/圈） |

**图标命名规范**：

```
ui_icon_[category]_[name]_[variant]_[size].png

示例：
ui_icon_skill_warrior_slash_40.png
ui_icon_status_poison_24.png
ui_icon_menu_settings_32.png
ui_icon_focus_diamond_16.png
```

### 7.3 UI动画感（UI Animation Feel）

**动画人格**：干脆、利落、有物理质感 — 像精密机械的开合，不是弹力凝胶的拉伸。UI元素像被磁铁吸到位，而不是被弹簧弹到位。

**三大动画原则**：

**原则A：快入快出，不拖泥带水**

- 入场动画时长上限 = 0.25秒（技能图标弹出、面板滑入、伤害数字出现）
- 退场动画时长上限 = 0.15秒（面板关闭、状态消失）
- 持续/循环动画周期 = 0.8-2秒（脉动、呼吸、充能）
- 缓动曲线：**Cubic ease-out** 作为默认（快速到达目标位置，缓慢停止）— 接近「磁吸」感
- **禁止**：Bounce（弹跳）、Elastic（弹性拉伸）、Back（过冲回弹）— 这些暗示柔软和玩闹感，与硬边语言矛盾

**原则B：状态变化必须有视觉回应**

每个UI状态转换都附带至少一个动画属性变化。不存在「突然跳变」。

| 状态变化 | 动画回应 | 时长 | 缓动 |
|---|---|---|---|
| 技能解锁 | 图标从中心缩放弹出（0→100%）+ 边框发光闪烁1次 | 0.25s | Cubic ease-out |
| 技能进入冷却 | 图标整体降亮度至50% + 叠加径向扫过的暗色遮罩 | 0.1s | Linear（遮罩扫过） |
| 技能冷却完成 | 图标亮度恢复 + 1px职业色闪光向外扩散 | 0.15s | Cubic ease-out |
| 专注值增量 | 填充区从左侧平滑推进 + 新填充段闪光 | 0.1s | Linear |
| 专注值满值 | 全条闪烁职业色（亮度100%↔70%，0.4秒周期） | 持续 | Sine波 |
| 血量下降 | 条内从右侧快速抽空 + 条体1px水平抖动 | 0.1s | Cubic ease-out |
| 血量危险区（<25%） | 最后一段脉冲（亮度周期变化，1秒周期）+ 微弱红色外发光 | 持续 | Sine波 |
| 面板打开 | 从目标边缘滑入（滑入距离=面板宽度30%）+ 背景模糊（2px→0px） | 0.2s | Cubic ease-out |
| 面板关闭 | 向打开方向滑出 + 不透明度降至0 | 0.15s | Cubic ease-in |
| 倒计时紧急 | 数字颜色渐变为战士红 + 微弱缩放脉冲（100%→103%→100%） | 持续 | Sine波 |
| 伤害数字 | 向上偏移15度飞出 + 缩放从120%→100% + 渐隐 | 0.6s浮出 + 0.3s渐隐 | Cubic ease-out |
| 手柄选中元素 | 1px职业色描边发光 + 内部亮度提升5% | 0.1s | Linear |

**原则C：循环动画不干扰阅读**

所有持续/循环动画（脉动、呼吸、充能）的视觉振幅被限制在不干扰文字/数值阅读的范围内：

- 亮度波动不超过 +/-15%
- 尺寸波动不超过 +/-3%
- 不使用位移循环（上下浮动）— 仅亮度和缩放
- 多个元素的循环动画必须错相（同屏幕内不出现完全同步的脉动）

**动画禁令**：

| 禁止效果 | 原因 |
|---|---|
| 弹跳缓动（Bounce） | 暗示柔软，与硬边语言矛盾 |
| 弹性缓动（Elastic） | 形状拉伸破坏几何纯度 |
| 过冲缓动（Back） | 不必要的「多余动作」，与利落感矛盾 |
| 持续旋转（>1圈） | 分散注意力，仅允许史诗边框装饰光线的缓慢旋转 |
| 抖动/震动循环 | 焦虑感，不适合休闲派对游戏 |
| 彩虹色循环 | 破坏色彩编码系统 |

### 7.4 HUD 摄制态 vs 屏幕空间（Diegetic vs Screen-Space）

**设计哲学**：职业对决的HUD以「屏幕空间固定UI」为主，极少量摄制态元素作为沉浸感点缀。不追求完全沉浸式HUD — 快节奏派对格斗需要即时信息获取，摄制态元素的信息延迟不可接受。

**元素归属矩阵**：

| UI元素 | 空间类型 | 位置 | 固定/跟随 | 理由 |
|---|---|---|---|---|
| 血条 | 屏幕空间 | 屏幕顶部，P1左侧/P2右侧对齐 | 固定 | 快速余光读取，不因角色位置变化而寻找 |
| 专注值条 | 屏幕空间 | 紧贴血条下方 | 固定 | 同上，资源条必须位置可预测 |
| 技能栏 | 屏幕空间 | 血条+专注值条下方，水平居中 | 固定 | 固定位置降低认知负担，手柄操作时不用低头找技能 |
| 倒计时/回合 | 屏幕空间 | 屏幕底部正中央 | 固定 | 参考大乱斗，时间信息居底不干扰战斗视觉焦点 |
| 伤害数字 | 世界空间（极简摄制态） | 命中点上方，向上偏移15度 | 跟随命中点 | 伤害发生位置即信息位置，直觉关联 |
| 技能解锁弹窗 | 屏幕空间 | 屏幕中央偏上（不遮挡角色） | 弹出后0.8秒淡出 | 事件重要性高需要居中，但必须快速消失 |
| "FIGHT!" / "VICTORY!" | 屏幕空间 | 屏幕正中央 | 全屏叠加层 | 系统级事件，需要100%注意力 |
| 角色名牌 | 屏幕空间 | 血条内侧左端 | 固定（随血条） | 标识血条归属，不跟随角色 |
| P1/P2标识 | 屏幕空间 | 血条外侧端角 | 固定（随血条） | 快速区分玩家 |
| 状态效果图标 | 摄制态 | 角色头顶上方 | 跟随角色 | 状态效果属于角色，需在混乱中定位「谁中了什么」 |
| 命中确认闪光 | 世界空间 | 命中点 | 跟随命中点 | 1-2帧白色闪光，反馈位置直觉关联 |
| 职业色起源连线 | 世界空间（摄制态） | 角色到特效起点 | 跟随施放者 | 0.15秒临时连线，帮助色盲玩家追踪归属 |

**为什么大多数元素是屏幕空间固定**：

1. **快速战斗支柱** — 单局2-5分钟，玩家没时间学习「信息在哪里」。固定位置 = 可预测 = 零学习成本
2. **高手菜鸟都开心** — 菜鸟不用在混乱中找血条，高手可以余光追踪多个信息源
3. **手柄导航** — 固定屏幕空间的UI元素可以精确映射到手柄方向键导航。摄制态元素难以做焦点管理

**为什么状态效果是摄制态**：

- 状态效果（中毒、沉默、减速）直接影响角色行为，信息必须绑在角色身上
- 混乱高潮时多个特效叠加，如果状态图标在屏幕边缘会与对应角色失去关联
- 摄制态状态下图标自动跟随角色，无需玩家做「哪个图标对应哪个角色」的心理映射

**屏幕布局精确参数**（1920x1080 基准）：

```
┌──────────────────────────────────────────────────────────┐
│ 顶部信息栏（≤8% = 86px）                                   │
│ ┌─ P1侧 ───────────────┐   ┌─ P2侧 ────────────────┐  │
│ │ [P1] 名牌  ████████░░ │   │ ░░████████ 名牌 [P2]  │  │
│ │ [专注] ▬▬▬▬▬▬▬▬░░░░░ │   │ ░░░░░▬▬▬▬▬▬▬▬ [专注]  │  │
│ │ [技能1][技能2][技能3]  │   │  [技能1][技能2][技能3] │  │
│ └───────────────────────┘   └────────────────────────┘  │
│                                                          │
│                      战斗区域                              │
│                   （角色 + 特效 + 场地）                     │
│                                                          │
│                     [ 2:45 ]                              │
│                   倒计时，底部中央                           │
└──────────────────────────────────────────────────────────┘
```

**安全区域**：
- 顶部信息栏区域（上方86px）：战斗层渲染在此区域之下，UI覆盖在上
- 底部倒计时区域（下方40px）：同理
- 左右各留80px安全边距：4K缩放时的安全区
- 所有UI元素锚定基于基准分辨率1920x1080，等比缩放到其他分辨率

### 7.5 无障碍设计（Accessibility）

**核心信条**：职业对决是派对游戏 — 派对游戏的门槛必须低到「任何人拿起手柄就能玩」。无障碍不是「可选的额外功能」，是设计要求。

#### 7.5.1 一瞥可读（Readable at a Glance）

**信息密度控制**：

- 同一时刻屏幕上可见的UI文字总量不超过 30 个字符（不含伤害数字）
- 每个信息块（血条、专注值条、技能图标组）之间间距不低于 8px
- 战斗状态下，UI元素的总面积不超过屏幕面积的 12%（顶部栏 + 底部计时器 + 状态图标）

**对比度保证**：

| 元素对 | 对比度要求 | WCAG等级 |
|---|---|---|
| UI文字 vs 背景 | ≥ 4.5:1 | AA |
| 系统大字 vs 任意背景 | ≥ 7:1 | AAA |
| 血条填充 vs 血条底板 | ≥ 3:1 | 大元素最低 |
| 伤害数字 vs 战斗背景 | ≥ 3:1 + 描边补偿 | 实际场景保证 |
| 图标符号 vs 底板 | ≥ 3:1 | 大元素最低 |

伤害数字特殊处理：即使在明亮特效背景上，1px纯白描边 + 1px纯黑投影（偏移1px右下）双重保障确保对比度。

**信息层级强化**：

每个关键信息至少通过 2 个视觉通道传达：

| 信息 | 主通道 | 备用通道 |
|---|---|---|
| 血量百分比 | 条长度 | 颜色（正常=职业色，危险=暗红脉动） |
| 专注值进度 | 填充量 | 每25%菱形图标标记 |
| 技能可用/冷却 | 图标亮度 | 径向扫过遮罩（剩余冷却时间） |
| 稀有度 | 边框颜色 | 边框线宽+图案（白纯线/紫虚线/金宽线） |
| 倒计时紧急 | 数字颜色变红 | 微弱缩放脉冲 + 底部边框闪烁 |
| 状态效果 | 图标 | 描述文字（tooltip） + 角色轮廓光变色 |

#### 7.5.2 手柄导航（Gamepad Navigation）

**导航模型**：焦点驱动（Focus-based），非指针驱动。

**手柄映射**：

| 输入 | 导航行为 |
|---|---|
| D-Pad 上/下/左/右 | 在同组UI元素间移动焦点 |
| 左摇杆 | 同D-Pad（带0.2秒死区防漂移） |
| A键（确认） | 激活当前焦点元素 |
| B键（返回） | 关闭当前面板/返回上一层 |
| LB/RB（肩键） | 切换顶层标签页（如有） |
| Start | 暂停/打开系统菜单 |

**焦点指示器**：

- 焦点元素获得 2px 职业色实线描边（与稀有度边框叠加时，焦点描边在最外层）
- 焦点元素亮度提升 5%
- 焦点移动时有微弱滑动音效（与声音设计师协调）
- 焦点循环：列表/网格末尾按同方向键回到起始位置（循环而非停止）
- **焦点入口点**：每次打开菜单/面板，焦点默认落在最常用或最安全的项目上（如：暂停菜单默认在「继续」而非「退出」）

**技能栏手柄操作**：

- 技能栏图标从左到右对应手柄按键 X/Y/B（或 LT/RT/LB，取决于最终映射）
- 技能不可用时，对应按键按下无反应（可选：微弱触觉反馈提示冷却中）
- 技能刚解锁时，对应图标闪烁 + 按键标签短暂放大提示

#### 7.5.3 色盲安全（Colorblind Safety）

**设计原则**：颜色永远是信息的增强通道，不是唯一通道。每种通过颜色传达的信息必须有非色彩备用通道。

**色盲模式选项**（设置菜单）：

| 模式 | 适用 | 调整内容 |
|---|---|---|
| 默认（色觉正常） | 大多数玩家 | 无调整 |
| 红色盲/绿色盲模式 | Protanopia / Deuteranopia | 战士红 → 暖橙 #E88A45；盗贼绿 → 青蓝 #2EC4B6；增加形状/图标区分权重 |
| 蓝黄色盲模式 | Tritanopia | 史诗金 → 亮粉 #E84593；稀有紫 → 青色 #45E8C5；增加边框线宽区分 |
| 高对比模式 | 任何视障 | 所有UI元素对比度强制≥7:1；描边宽度翻倍；伤害数字尺寸+50% |

**色盲模式的实现规则**：

1. 色盲模式只改变颜色映射，不改变布局或动画（保持肌肉记忆一致）
2. 切换色盲模式后提供 3 秒预览，确认后保存
3. 色盲模式下额外强化形状通道：角色轮廓光更明显、状态图标更大（+4px）
4. 伤害数字在色盲模式下始终显示 1px 描边（默认模式暴击才有描边）

**已内置的非色彩通道**（无需色盲模式即生效）：

- 形状语言：战士矩形 / 法师三角 / 盗贼菱形（Section 3.1-3.3）
- P1/P2 文字标识 + 不同几何边框（P1方形、P2圆形）（Section 4.5）
- 稀有度边框线宽差异（1/2/3px）（Section 7.2）
- 起源连线（Section 4.5）
- 亮度差异（Section 4.5）

#### 7.5.4 文本可读性

- **最小可交互文字 12px**，最小纯展示文字 10px
- **伤害数字最小 16px** — 这是战斗中的关键信息，低于此尺寸在高动态场景下不可读
- **文字描边**：所有悬浮在战斗层上的文字（伤害数字、状态文字）必须有 1px 纯黑描边
- **文字投影**：系统大字（"FIGHT!"、"VICTORY!"）允许 2px 模糊投影增加可读性
- **禁止文字旋转** — 除伤害数字的15度倾斜外，所有UI文字保持水平。旋转文字在高动态场景下难以阅读
- **自动换行**：描述文本宽度上限 300px（1920x1080基准），超出自动换行

#### 7.5.5 运动敏感

- 屏幕震动提供开关选项（默认开启，可关闭）
- 关闭后屏幕震动替换为角色边缘白色闪烁（同等信息量，无位移）
- UI弹窗/弹出动画提供「简化」选项：替换所有缩放/滑动动画为简单淡入淡出（时长不变）
- **不提供完全关闭动画选项** — 状态变化无视觉回应会导致信息缺失（违反原则B），但可以简化

### 7.6 UI材质与表面语言

**UI表面 = 数字面板，不是物理材质**。UI不需要模拟皮革、金属、木头 — 它是竞技场的电子记分牌。

**底板语言**：

| 层级 | 颜色 | 不透明度 | 用途 |
|---|---|---|---|
| 一级面板底板 | #1A1A2E（深渊底） | 90% | 大型面板（暂停菜单、设置、技能详情） |
| 二级面板底板 | #222240（暖色变体） | 85% | 弹窗、确认对话框 |
| 条形底板 | #1A1A2E | 70% | 血条、专注值条背景槽 |
| 图标底板 | #2A2A3E | 100% | 技能图标方形底 |
| 悬浮提示底板 | #1A1A2E | 95% | Tooltip、简短文字气泡 |

**分隔与层次**：

- 面板间分隔线：1px，#3A3A5C（UI中性灰），不透明度60%
- 面板圆角：8px（约5%），极简圆角 — 不是完全直角（避免过于生硬），也不是大圆角（避免与环境混淆）
- 面板阴影：无投影、无模糊 — UI通过色值差异和层级叠加区分，不依赖阴影
- 面板描边：1px #3A3A5C 外描边 — 轻微定义边缘，不喧宾夺主

**面板层级叠加规则**：

- 弹窗/模态框下方的游戏画面叠加一层 #1A1A2E 60%不透明度遮罩
- 弹窗可以叠加在弹窗上（最多2层），每层遮罩递增15%不透明度
- 暂停菜单弹出时游戏完全冻结 + 全屏遮罩

## 9. Reference Direction

### 参考1：Rivals of Aether（游戏）

**借鉴**：角色剪影的极端差异化设计。每个角色的 idle 动画通过体型比例、重心高低、运动节奏三个维度完成身份识别，不需要看颜色就能区分。

**规避**：像素风渲染技法和逐帧手绘动画管线。几何矢量风格不需要像素级纹理细节 — 过多细节会削弱几何形状的表达力。

**为什么重要**：职业对决有随机技能改变角色轮廓的机制。Rivals 证明了"剪影即身份"不需要依赖纹理，仅靠形状比例和运动特征就能实现 — 这是我们形状语言系统需要达到的品质标杆。

### 参考2：Malevich / 几何抽象主义构图规则（艺术风格）

**借鉴**：至上主义构图法则 — 在深色/中性底色上用少量高纯度几何形状构建视觉焦点。具体：通过形状的尺寸对比（一个大型元素+几个小型元素）和位置偏移（永远不完全居中，微偏）创造动态张力。

**规避**：完全抽象化和哲学宣言。构图法则服务于可读性和信息传达，不是美学冥想。

**为什么重要**：为视觉层级系统提供理论根基 — 少量高纯度形状在深底上可同时实现高冲击力和清晰信息层级。角色就是画布上的大型红色方块，特效和环境是辅助形状。他的"微偏构图"直接适用于平台布局设计。

### 参考3：哪吒之魔童降世 — 能量爆发表达（电影）

**借鉴**：能量积累到释放的"收缩-静止-爆发"三拍子节奏。这个时间语法不依赖具体的火焰/雷电/粒子样式，是通用的能量表达结构。

**规避**：写实渲染技法（光影体积感、烟雾粒子模拟、3D光照）和具体的视觉内容（传统美术元素、文化符号）。只借鉴时间节奏。

**为什么重要**：整个对局是宏观能量积累（开局→高潮），每次技能解锁是微观能量爆发。三拍子节奏为技能解锁动画提供精确模板 — 0.1秒收缩+0.05秒静止+0.1秒爆发 = 0.25秒解锁动画。

### 参考4：Thumper（游戏）

**借鉴**：深色空间中高纯度几何形状的灯光处理。形状本身就是光源，背景是纯粹的负空间。通过发光强度变化（而非颜色变化）传达紧张度升级。

**规避**：恐怖/压迫情绪基调和节拍精确同步机制。职业对决从冷静升温到沸腾庆祝，不是从紧张到崩溃。发光语法可以用，情绪方向完全相反。

**为什么重要**：证明了"深底+自发光形状"能产生极强视觉冲击力，且不需要复杂光照管线 — 对独立项目极其重要。角色轮廓光、能量脉动、技能特效都是"自发光几何形状"。用同一组颜色的亮度变化（30%→90%）完成情绪升级，无需引入新颜色。

### 参考5：Overcooked（游戏）

**借鉴**：多人派对游戏的胜利/失败情绪表达。胜利创造"大家一起欢呼"的庆祝感，失败营造"没关系再来一次"的轻松鼓励 — 不惩罚、不暗淡、不使用负面视觉语言。多人场景中每个玩家有独立的视觉反馈通道。

**规避**：3D卡通渲染风格、Q版角色比例、厨房/食物主题。只借鉴派对游戏的多人情绪反馈设计思路。

**为什么重要**：直接支持失败情绪设计（败者色脉动+2%/周期，暗示"能量在积蓄"）。Overcooked 的多玩家 UI 反馈分离策略验证了 P1/P2 信息必须物理分离的设计原则。
